Comment ajouter un widget Left au Centre de notifications du Mac

Le Centre de notifications du Mac comporte un panneau de widgets que tu ouvres d’un clic sur l’horloge. Avec macOS Sonoma ou ultérieur, il peut afficher les widgets des apps de ton iPhone, dont Left.

Prérequis

Pour afficher des widgets Left dans le Centre de notifications, il faut :

  • macOS Sonoma (14) ou version ultérieure sur ton Mac
  • Un iPhone avec Left installé, connecté avec le même compte Apple que ton Mac et à proximité, ou sur le même réseau Wi-Fi, avec l’option Utiliser les widgets de l’iPhone activée (Réglages Système → Bureau et Dock → Widgets)

Étape 1 : configure Left sur ton iPhone

Les widgets du Centre de notifications sont affichés depuis ton iPhone : installe d’abord Left sur ton iPhone depuis l’App Store.

Étape 2 : ouvre le Centre de notifications

  1. Clique sur la date et l’heure dans le coin supérieur droit de la barre des menus.
  2. Le panneau du Centre de notifications apparaît par la droite.
  3. Fais défiler jusqu’en bas du panneau et clique sur Modifier les widgets.

Étape 3 : ajoute des widgets Left

  1. Dans l’éditeur de widgets, cherche « Left » dans le champ de recherche ou fais défiler pour le trouver.
  2. Clique sur le bouton + d’un widget Left pour l’ajouter, ou fais-le glisser dans le panneau du Centre de notifications.
  3. La galerie de widgets indique les tailles que propose chaque widget Left : ajoutes-en autant que tu veux.
  4. Clique sur OK quand tu as terminé.

Étape 4 : choisis l’événement à afficher

  1. Fais un clic droit (ou Ctrl-clic) sur un widget Left dans le Centre de notifications.
  2. Choisis Modifier le widget.
  3. Pour un widget À venir, appuie sur Choisir une date et sélectionne la date à afficher.
  4. Clique en dehors du widget pour enregistrer.

Conseils pour les utilisateurs de Mac

  • Tu peux réorganiser les widgets du Centre de notifications en les faisant glisser vers le haut ou vers le bas.
  • Cliquer sur un widget Left dans le Centre de notifications peut te demander de continuer sur ton iPhone, car le widget vient de Left sur ton iPhone.
  • Pour un compte à rebours toujours visible sur le bureau de ton Mac, consulte le guide des widgets du bureau Mac.
  • Les widgets affichent les données de Left sur ton iPhone : toute date que tu y crées leur est donc disponible.
