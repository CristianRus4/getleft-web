Comment ajouter un widget Left sur ton écran d'accueil iPad

Le grand écran du iPad le rend parfait pour les widgets visibles. Voici comment ajouter Left à ton écran d'accueil iPad afin que tes comptes à rebours soient toujours visibles.

Étape 1 — Configurez ton événement dans Left

  1. Ouvre l'application Left sur ton iPad (téléchargez-la depuis le App Store si tu ne l'avez pas déjà fait - Left est une application universelle, donc un achat couvre à la fois le iPhone et le iPad).
  2. Appuie sur + pour créer un nouvel événement ou appuyez sur un événement existant pour le modifier.
  3. Définissez le nom, la date et le style d'affichage.
  4. Appuie sur Enregistrer.

Étape 2 — Entrez dans le mode d'édition du widget

  1. Va à ton écran d’accueil iPad.
  2. Appuie longuement sur sur n'importe quelle zone vide de l'écran jusqu'à ce que les icônes commencent à trembler.
  3. Appuie sur le bouton + dans le coin supérieur gauche pour ouvrir la galerie de widgets.

Étape 3 — Ajoute le widget Left

  1. Dans la galerie de widgets, recherchez "Left" ou faites défiler pour le trouver.
  2. Appuie sur Left pour voir les tailles de widget disponibles.
  3. Fais défiler les tailles – petite, moyenne, grande et extra-large (iPad uniquement) – et appuyez sur Ajouter un widget.
  4. Fais glisser le widget vers la position souhaitée sur ton écran d'accueil.
  5. Appuie sur Done dans le coin supérieur droit.

Étape 4 — Configurez le widget

  1. Appuie longuement sur le widget Left que vous venez d'ajouter.
  2. Appuie sur Modifier le widget.
  3. Sélectionne l'événement que tu veux afficher ou utilisez le mode Smart pour une sélection automatique en fonction de ce qui se produira le plus tôt.
  4. Appuie en dehors du widget pour enregistrer.

Tailles des widgets iPad

Sur iPad, Left prend en charge quatre tailles de widget:

  • Small (2×2) — compact, affiche le nom de l'événement et la valeur principale
  • Medium (4×2) — affiche le nom de l'événement, la répartition (jours/heures) et une barre de progression
  • Grand (4×4) — détails complets avec anneau de progression et plusieurs unités d'affichage
  • Extra Large (8×4, iPad uniquement) — widget panoramique affichant plusieurs événements ou des détails riches

Utilisation de la vue Aujourd'hui sur iPad

Tu peux également ajouter des widgets Left à la vue Aujourd'hui du iPad (faites glisser ton doigt vers la droite depuis l'écran d'accueil). Cela conserve tes comptes à rebours dans un panneau de widgets dédié sans occuper d'espace sur l'écran d'accueil. Les mêmes étapes s'appliquent: appuyez longuement sur la vue Aujourd'hui et appuyez sur + pour ajouter Left.
