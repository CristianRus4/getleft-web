Comment ajouter un widget Left à l’écran d’accueil de ton iPad

Le grand écran de l’iPad est idéal pour des widgets lisibles d’un coup d’œil. Voici comment ajouter Left à l’écran d’accueil de ton iPad pour que tes comptes à rebours restent toujours visibles.

Étape 1 : configure ton événement dans Left

  1. Ouvre l’app Left sur ton iPad (télécharge-la depuis l’App Store si ce n’est pas déjà fait).
  2. Va dans À venir et appuie sur + pour ajouter une date. Pour une habitude, une série ou un objectif, utilise plutôt Depuis.
  3. Définis le nom, la date et le style d’affichage.
  4. Appuie sur la coche pour enregistrer.

Étape 2 : passe en mode de modification des widgets

  1. Va sur l’écran d’accueil de ton iPad.
  2. Maintiens le doigt sur une zone vide de l’écran jusqu’à ce que les icônes se mettent à bouger.
  3. Appuie sur Modifier en haut de l’écran, puis sur Ajouter un widget.

Étape 3 : ajoute le widget Left

  1. Dans la galerie de widgets, cherche « Left » ou fais défiler pour le trouver.
  2. Appuie sur Left pour voir les tailles de widget disponibles.
  3. Fais défiler les widgets et leurs tailles. Pour un compte à rebours, choisis À venir ; quand tu vois la taille voulue, appuie sur Ajouter un widget.
  4. Fais glisser le widget à l’endroit voulu sur ton écran d’accueil.
  5. Appuie sur OK dans le coin supérieur droit.

Étape 4 : choisis l’événement affiché par le widget

  1. Maintiens le doigt sur le widget Left que tu viens d’ajouter.
  2. Appuie sur Modifier le widget.
  3. Pour un widget À venir, appuie sur Choisir une date et sélectionne la date à afficher.
  4. Appuie en dehors du widget pour enregistrer.

Tailles des widgets sur iPad

Sur iPad, les widgets Left existent en jusqu’à quatre tailles. La galerie de widgets indique celles que propose chaque widget :

  • Petit (2×2) : une date ou un compteur d’un coup d’œil
  • Moyen (4×2) : plus de détails ; les widgets de liste, comme la liste Temps futur et la liste de séries, commencent à cette taille
  • Grand (4×4) : le plus d’espace pour un seul widget
  • Très grand (iPad uniquement) : proposé par les widgets de type liste, comme la liste Temps futur, la liste de séries, Habitudes et Planificateur

Utiliser la vue Aujourd’hui sur iPad

Tu peux aussi ajouter des widgets Left à la vue Aujourd’hui de l’iPad (balaie vers la droite depuis l’écran d’accueil). Tes comptes à rebours restent ainsi dans un panneau de widgets dédié, sans occuper de place sur l’écran d’accueil. Les étapes sont les mêmes : maintiens le doigt sur la vue Aujourd’hui et appuie sur + pour ajouter Left.
