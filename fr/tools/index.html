Outils de temps gratuits

Une collection d’outils petits et rapides, qui ne cesse de grandir, créée par l’équipe de Left. Fais un compte à rebours jusqu’à une date, calcule le temps entre deux moments, le nombre de jours depuis un événement, les jours ouvrés, les jours d’école, le sommeil, le jeûne, la progression de l’année, les fuseaux horaires, les timestamps Unix et plus encore. Pour les widgets iPhone, les habitudes, les séries, les dates À venir, les suivis Depuis et le Planificateur, télécharge Left.

Left met aussi ça sur ton écran d’accueil : le widget de compte à rebours, le widget de jours écoulés et le widget de progression de l’année.
