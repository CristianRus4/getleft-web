So öffnen Sie Left mit dem iPhone Action Button

Dem Action Button auf iPhone 15 Pro, iPhone 16 und späteren Modellen kann die Ausführung einer Verknüpfung zugewiesen werden – einschließlich einer Verknüpfung, die Left direkt öffnet. So richten Sie es ein.

Was Sie brauchen

  • iPhone 15 Pro / Pro Max oder iPhone 16-Serie oder neuer – der Action Button ist für diese Modelle verfügbar
  • Left auf deinem iPhone installiert
  • Shortcuts-App – integriert in iOS, kein Download erforderlich

Schritt 1 – Erstelle eine Verknüpfung, die Left öffnet

  1. Öffne die Shortcuts-App.
  2. Tippe auf die Schaltfläche +, um eine neue Verknüpfung zu erstellen.
  3. Tippe auf Aktion hinzufügen und suchen Sie dann nach „App öffnen“.
  4. Tippe in der Aktion auf das Feld App und wählen Sie Left aus.
  5. Tippe oben auf den Verknüpfungsnamen und benennen Sie ihn in etwa „“LeftÖffnen““ um.
  6. Tippe auf Fertig.

Schritt 2 – Weisen Sie die Verknüpfung dem Action Button zu

  1. Öffne Einstellungen → Aktionsschaltfläche.
  2. Wischen Sie durch die Optionen, bis Sie Shortcut erreichen.
  3. Tippe auf Wähle eine Verknüpfung aus und wählen Sie die gerade erstellte Verknüpfung "Left öffnen" aus.
  4. Exit Settings – Action Button ist jetzt konfiguriert.

Schritt 3 – Testen Sie es

Halte die Action Button (die Taste am oberen linken Rand deines iPhone) gedrückt. Left sollte sofort geöffnet werden, auch über den Sperrbildschirm.

Erweitert: Öffne ein bestimmtes Left-Ereignis

Wenn Left URL-Schema-Deep-Left unterstützt, kannst du ein bestimmtes Ereignis direkt öffnen. Sieh sich die Anleitung Left Shortcuts für verfügbare URL-Aktionen an und erfahren Sie, wie Sie eine Verknüpfung erstellen, die ein benanntes Ereignis anstelle des Hauptbildschirms der App öffnet.

Weitere nützliche Action Button-Aufgaben

Der Action Button unterstützt jeweils nur eine Zuweisung, Du kannst jedoch eine Menüverknüpfung verwenden, um mehrere Optionen anzuzeigen. Erstelle eine Verknüpfung mit der Aktion „Aus Menü auswählen“, die mehrere Optionen auflistet (Left öffnen, Timer starten, Stummschalten) – der Action Button zeigt dann bei jedem Drücken eine Auswahl an.
