So machen Sie Left-Widgets transparent

Left ist so konzipiert, dass es sowohl außerhalb als auch innerhalb der App funktioniert. Mit den Widgets „Startbildschirm“, „Sperrbildschirm“ und „StandBy“ kannst du deine verbleibende Zeit, bevorstehende Termine, Gewohnheiten und Streaks sichtbar halten, ohne Left jedes Mal öffnen zu müssen, wenn du sie überprüfen möchten. Auf iPhone wird die Widget-Transparenz durch iOS gesteuert, nicht durch eine Einstellung innerhalb von Left – der Ablauf ist also: Füge das Left-Widget hinzu, rufen Sie den Bearbeitungsmodus für den Startbildschirm auf und ändern Sie dann das Widget-Erscheinungsbild auf Clear.

Schritt 1 – Füge ein Left-Widget hinzu

Füge zunächst das Left-Widget hinzu, das du verwendest möchten.

  1. Drücke lange auf einen leeren Bereich deines iPhone-Startbildschirms.
  2. Tippe auf die Schaltfläche +.
  3. Suche nach Left.
  4. Wähle das gewünschte Widget aus und fügen Sie es deinem Startbildschirm hinzu.
  5. Platzieren Sie es dort, wo es angezeigt werden soll.

Der transparente Stil wird von iOS gesteuert, daher muss sich das Widget auf dem Startbildschirm befinden, bevor Sie sein Erscheinungsbild anpassen.

Schritt 2 – Wechseln Sie in den Wackelmodus

Sobald das Widget auf deinem Startbildschirm angezeigt wird:

  1. Drücke erneut lange auf den Startbildschirm.
  2. Warten Sie, bis sich die Apps und Widgets zu bewegen beginnen.
  3. Bleiben Sie auf diesem Bildschirm. Dies ist derselbe Modus, den Sie zum Verschieben oder Entfernen von Apps und Widgets verwenden.

Schritt 3 – Widgets auf „Löschen“ ändern

Oben auf dem Bildschirm:

  1. Tippe auf Bearbeiten.
  2. Tippe auf Anpassen.
  3. Wähle Clear.
  4. Tippe außerhalb des Anpassungsbereichs oder beenden Sie die Bearbeitung, wenn du fertig sind.

deine Left-Widgets sollten jetzt den klaren Startbildschirmstil verwenden, damit sie natürlicher über deinem Hintergrund erscheinen.

Fehlerbehebung

  • Ich sehe Clear nicht. Stelle sicher, dass dein iPhone auf eine Version von iOS aktualisiert ist, die ein klares Widget-Styling unterstützt.
  • Das Widget hat immer noch einen Hintergrund. Entferne das Widget und fügen Sie es erneut hinzu. Wiederholen Sie dann Edit → Customize → Clear.
  • Nur einige Widgets haben sich geändert. Die Option zum Löschen ist eine iOS-Einstellung für das Erscheinungsbild des Startbildschirms. Überprüfen Sie, ob Sie die richtige Startbildschirmseite und den richtigen Widget-Stil anpassen.
