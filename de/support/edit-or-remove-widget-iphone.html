Bearbeiten Sie ein Widget (ändern Sie, was es anzeigt)

  1. Gehe zu deinem iPhone-Startbildschirm.
  2. Drücke lange auf das Widget, das Sie bearbeiten möchten, bis ein Menü angezeigt wird.
  3. Tippe auf Widget bearbeiten.
  4. Ändern Sie das Ereignis, den Anzeigestil oder alle anderen für dieses Widget verfügbaren Einstellungen.
  5. Tippe zum Speichern auf eine beliebige Stelle außerhalb des Widgets.

Verschieben Sie ein Widget an eine andere Position

  1. Drücke lange auf ein App-Symbol oder Widget, bis die Symbole zu wackeln beginnen (Wackelmodus).
  2. Ziehe das Widget an seine neue Position – Du kannst es innerhalb derselben Startbildschirmseite verschieben oder an den Rand ziehen, um es auf eine andere Seite zu verschieben.
  3. Tippe auf Done, wenn du fertig sind.

Entferne ein Widget vom Startbildschirm

  1. Drücke lange auf das Widget, bis ein Menü angezeigt wird.
  2. Tippe auf Widget entfernen.
  3. Bestätigen Sie das Entfernen im angezeigten Dialog.

Durch das Entfernen eines Widgets werden deine Left-Ereignisse gelöscht – es wird lediglich das Widget vom Startbildschirm entfernt. Du kannst es jederzeit wieder hinzufügen.

Größe eines Widgets ändern

iOS unterstützt keine Größenänderung vorhandener Widgets. So ändern Sie die Größe eines Left-Widgets:

  1. Entferne das aktuelle Widget (langes Drücken → Widget entfernen).
  2. Drücke lange auf einen leeren Bereich → tippen Sie auf +.
  3. Finden Sie Left in der Widget-Galerie.
  4. Wischen Sie zur gewünschten Größe und tippen Sie dann auf Widget hinzufügen.

Bearbeiten Sie ein Sperrbildschirm-Widget

  1. Drücke lange auf den Sperrbildschirm und tippen Sie auf Anpassen.
  2. Tippe auf ein Widget, um es zu ersetzen, oder tippen Sie auf die Schaltfläche – auf einem vorhandenen Widget, um es zu entfernen.
  3. Tippe auf Done, wenn du fertig sind.

Widget wird nicht aktualisiert?

Wenn ein Left-Widget hängen bleibt oder einen alten Wert anzeigt:

  • Öffne die Left-App einmal – dies erzwingt eine Widget-Aktualisierung.
  • Entferne das Widget und fügen Sie es erneut hinzu, um es zurückzusetzen.
  • Überprüfen Sie, ob die Hintergrund-App-Aktualisierung für Left unter Einstellungen → Left → Hintergrund-App-Aktualisierung aktiviert ist.
