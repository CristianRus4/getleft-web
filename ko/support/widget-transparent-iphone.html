Left 위젯을 투명하게 만드는 방법

Left는 앱 내부뿐만 아니라 외부에서도 작동하도록 설계되었습니다. 홈 화면, 잠금 화면 및 StandBy 위젯을 사용하면 확인하고 싶을 때마다 Left를 열지 않고도 남은 시간, 다가오는 날짜, 습관 및 연속 기록을 볼 수 있습니다. iPhone에서 위젯 투명도는 Left 내부 설정이 아닌 iOS에 의해 제어됩니다. 따라서 흐름은 다음과 같습니다. Left 위젯을 추가하고 홈 화면 편집 모드로 들어간 다음 위젯 모양을 Clear로 전환합니다.

이 페이지의 내용

  • 1단계 - Left 위젯 추가
  • 2단계 - 흔들림 모드로 전환
  • 3단계 - 위젯을 지우기로 변경
  • 문제 해결

1단계 - Left 위젯 추가

사용하려는 Left 위젯을 추가하여 시작하세요.

  1. iPhone 홈 화면의 빈 공간을 길게 누르세요.
  2. + 버튼을 탭하세요.
  3. Left를 검색하세요.
  4. 원하는 위젯을 선택하고 홈 화면에 추가하세요.
  5. 표시하고 싶은 위치에 배치하세요.

투명 스타일은 iOS에 의해 제어되므로 위젯의 모양을 사용자 정의하기 전에 홈 화면에 있어야 합니다.

2단계 - 흔들림 모드로 전환

위젯이 홈 화면에 나타나면 다음 단계를 따르세요.

  1. 홈 화면을 다시 길게 누르세요.
  2. 앱과 위젯이 움직이기 시작할 때까지 기다리세요.
  3. 이 화면에 머무르세요. 이는 앱과 위젯을 이동하거나 제거하는 데 사용하는 것과 동일한 모드입니다.

3단계 - 위젯을 지우기로 변경

화면 상단에서:

  1. Edit를 탭하세요.
  2. 사용자 지정를 탭합니다.
  3. Clear를 선택합니다.
  4. 완료되면 사용자 정의 패널 외부를 탭하거나 편집을 완료하세요.

이제 Left 위젯이 명확한 홈 화면 스타일을 사용하므로 배경화면 위에 더 자연스럽게 배치됩니다.

문제 해결

  • Clear가 표시되지 않습니다. iPhone가 명확한 위젯 스타일을 지원하는 iOS 버전으로 업데이트되었는지 확인하세요.
  • 위젯에는 여전히 배경이 있습니다. 위젯을 제거하고 다시 추가한 다음 Edit → Customize → Clear를 반복합니다.
  • 일부 위젯만 변경되었습니다. 지우기 옵션은 iOS 홈 화면 모양 설정입니다. 올바른 홈 화면 페이지와 위젯 스타일을 사용자 정의하고 있는지 확인하세요.
