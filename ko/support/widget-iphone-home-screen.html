iPhone 홈 화면에 Left 위젯을 추가하는 방법

Left 카운트다운 및 진행 위젯은 iPhone 홈 화면에서 바로 실시간 업데이트되어 하루 종일 업데이트될 수 있습니다. 몇 번의 탭만으로 추가하는 방법은 다음과 같습니다.

  • 2단계 - 홈 화면에 위젯 추가
  • 3단계 - 위젯에 표시할 이벤트 선택
  • 위젯 크기 변경
  • 팁

1단계 - Left에서 이벤트 설정

위젯을 추가하기 전에 표시하려는 이벤트를 생성하거나 맞춤설정하세요.

  1. iPhone에서 Left 앱을 엽니다.
  2. +를 눌러 새 이벤트를 생성하거나 기존 이벤트를 눌러 편집하세요.
  3. 이름을 지정하고 날짜를 설정하고 카운트다운, 이후 또는 백분율 등 표시 스타일을 선택합니다.
  4. 저장를 탭하세요.

2단계 - 홈 화면에 위젯 추가

  1. iPhone 홈 화면으로 이동하여 아이콘이 흔들리기 시작할 때까지 빈 공간을 길게 누르세요.
  2. 왼쪽 상단에 있는 + 버튼을 탭하세요.
  3. 위젯 갤러리에서 "Left"를 검색하거나 스크롤하여 찾으세요.
  4. 사용 가능한 크기(소형, 중형, 대형)를 스와이프하고 원하는 크기에서 위젯 추가를 탭하세요.
  5. 위젯을 원하는 홈 화면 위치로 끈 다음 Done를 탭하세요.

3단계 - 위젯에 표시할 이벤트 선택

  1. 새로 추가된 Left 위젯을 길게 누르세요.
  2. Edit Widget를 탭하세요.
  3. 표시하려는 이벤트를 선택하거나 Smart에 남겨두면 Left가 가장 관련성이 높은 다가오는 이벤트를 자동으로 선택할 수 있습니다.
  4. 저장하려면 위젯 바깥쪽 아무 곳이나 탭하세요.

위젯 크기 변경

Left는 세 가지 홈 화면 위젯 크기를 지원합니다.

  • Small (2×2) — 이벤트 이름과 기본 카운트다운 번호를 표시합니다.
  • Medium (4×2) — 이벤트 이름, 요일/시간 분석 및 선택적 진행률 표시줄을 표시합니다.
  • Large (4×4) — 시각적 진행 링과 여러 장치를 포함한 전체 세부 정보를 표시합니다.

크기를 변경하려면 위젯을 제거하고 새 크기로 다시 추가하거나, iOS 버전이 크기 조정을 지원하는 경우 위젯 편집 흐름을 사용하세요.

팁

  • 위젯은 주기적으로 업데이트됩니다. iOS는 배터리를 보존하기 위해 정확한 새로 고침 빈도를 제어합니다. 최신 시간을 보려면 Left 앱을 직접 엽니다.
  • 여러 홈 화면 페이지에 걸쳐 다양한 이벤트를 가리키는 여러 Left 위젯을 추가할 수 있습니다.
  • 휴대폰이 잠겨 있는 경우에도 표시되는 카운트다운은 잠금 화면 위젯 가이드를 참조하세요.
