iPhone Action Button로 Left를 여는 방법

iPhone 15 Pro, iPhone 16 및 이후 모델의 Action Button는 Left를 직접 여는 단축키를 포함하여 단축키를 실행하도록 할당할 수 있습니다. 설정 방법은 다음과 같습니다.

필요한 것

  • iPhone 15 Pro/Pro Max 또는 iPhone 16 시리즈 이상 — Action Button는 이 모델에서 사용할 수 있습니다.
  • iPhone에 설치된 Left
  • Shortcuts app — iOS에 내장되어 있어 다운로드가 필요하지 않습니다.

1단계 - Left를 여는 바로가기 만들기

  1. Shortcuts 앱을 엽니다.
  2. + 버튼을 눌러 새 바로가기를 만듭니다.
  3. 액션 추가를 누른 다음 "앱 열기"를 검색하세요.
  4. 작업에서 App 필드를 탭하고 Left를 선택합니다.
  5. 상단의 바로가기 이름을 탭하고 "Open Left"와 같은 이름으로 이름을 바꿉니다.
  6. 완료를 탭하세요.

2단계 - Action Button에 바로가기 할당

  1. Settings → 액션 버튼를 엽니다.
  2. Shortcut에 도달할 때까지 옵션을 스와이프하세요.
  3. 바로가기 선택를 누르고 방금 만든 "Open Left" 바로가기를 선택합니다.
  4. 종료 설정 — 이제 Action Button가 구성되었습니다.

3단계 - 테스트

Action Button(iPhone의 왼쪽 상단 가장자리에 있는 버튼)을 길게 누릅니다. Left는 잠금 화면에서도 즉시 열립니다.

고급: 특정 Left 이벤트 열기

Left가 URL 체계 딥링크를 지원하는 경우 특정 이벤트를 직접 열 수 있습니다. Left 단축키 가이드에서 사용 가능한 URL 작업과 앱의 기본 화면이 아닌 명명된 이벤트를 여는 단축키를 만드는 방법을 확인하세요.

기타 유용한 Action Button 할당

Action Button는 한 번에 하나의 할당을 지원하지만 메뉴 바로가기를 사용하여 여러 옵션을 제공할 수 있습니다. 여러 옵션(Left 열기, 타이머 시작, 음소거)을 나열하는 "메뉴에서 선택" 작업으로 바로가기를 생성합니다. 그런 다음 Action Button는 누를 때마다 선택기를 표시합니다.
