Mac 데스크탑에 Left 위젯을 추가하는 방법

macOS Sonoma는 데스크탑에 직접 위치하여 항상 앱 창 뒤에서 볼 수 있는 대화형 위젯을 도입했습니다. Mac 데스크탑에 Left를 설치하는 방법은 다음과 같습니다.

요구사항

  • macOS Sonoma (14) 이상 — 데스크톱 위젯은 Sonoma 기능입니다.
  • Mac에 설치된 Left — Mac App Store에서 "Left"를 검색하세요.

1단계 - Mac에 Left 설치

Left는 범용 구매입니다. 동일한 Apple ID 아래 iPhone 또는 iPad에 보유하고 있는 경우 추가 비용 없이 Mac App Store에서 Mac에 다운로드하세요. Mac App Store를 열고 "Left"를 검색하세요.

2단계 - 위젯을 추가하려면 데스크탑을 마우스 오른쪽 버튼으로 클릭하세요.

  1. Mac 데스크탑의 빈 공간을 클릭하여 초점이 맞춰진 앱이 없는지 확인하세요.
  2. 바탕 화면에서 를 마우스 오른쪽 버튼으로 클릭(또는 Control 클릭)합니다.
  3. 컨텍스트 메뉴에서 Edit Widgets…를 선택합니다.

3단계 - Left 찾기 및 추가

  1. 위로 슬라이드되는 위젯 편집기에서 "Left"를 검색하거나 스크롤하세요.
  2. Left 위젯의 + 버튼을 클릭하여 데스크탑에 추가하거나 특정 위치로 드래그하세요.
  3. 완료를 클릭합니다.

4단계 - 위젯 구성

  1. 데스크탑에서 Left 위젯을 마우스 오른쪽 버튼으로 클릭하세요.
  2. Edit 위젯를 선택합니다.
  3. 표시할 이벤트를 선택하거나 자동 선택을 위해 Smart를 사용하세요.
  4. Esc를 누르거나 다른 곳을 클릭하여 저장하세요.

데스크탑 위젯 이동 및 크기 조정

  • 데스크탑 위젯을 클릭하고 드래그하여 데스크탑의 어느 위치에나 재배치할 수 있습니다.
  • macOS Sonoma의 데스크탑 위젯은 중소형 크기로 제공됩니다. 크기를 변경하려면 제거하고 다시 추가하세요.
  • 위젯은 앱 창 뒤에 계층화되어 있으며 데스크탑을 표시할 때 표시됩니다(트랙패드에서 네 손가락으로 위쪽 및 바깥쪽으로 스와이프하거나 Mission Control 누르기).

위젯 상호작용

macOS Sonoma 및 이후 버전에서는 데스크톱 위젯이 대화형입니다. Left 위젯을 클릭하면 Dock 또는 응용 프로그램 폴더에서 찾을 필요 없이 Left 앱을 직접 열 수 있습니다.
