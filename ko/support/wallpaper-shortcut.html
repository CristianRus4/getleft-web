Left Wallpaper 단축키 설정 방법

Left Wallpaper는 잠금 화면을 연간 진행 상황, 주 단위 수명, 카운트다운 또는 사진과 시간 보기의 혼합 등 시간을 실시간으로 보여주는 화면으로 바꿔줍니다. 최신 상태로 유지하려면 하루에 한 번 실행되는 Apple Shortcuts 자동화에 연결합니다. 전체 설정은 다음과 같습니다.

이 페이지의 내용

  • 1단계 - 새 바로가기 만들기
  • 2단계 - 바로가기 만들기
  • 3단계 - 자동화 생성
  • 4단계 - 바로가기 자동화
  • 문제 해결
  • 팁 - 잠금 화면 위젯과 페어링하세요

1단계 - 새 바로가기 만들기

Left 앱 내부에서 바로가기 열기를 탭하여 바로가기 앱으로 이동합니다. 그런 다음:

  1. 바로가기에서 오른쪽 상단에 있는 + 버튼을 탭하여 새 바로가기를 만듭니다.
  2. 하단에 검색창이 있는 빈 편집기가 표시됩니다. 여기에 두 가지 작업을 추가하게 됩니다.

2단계 - 바로가기 만들기

다음 순서로 두 가지 작업을 추가합니다.

  1. 액션 검색창에 "Left wallpaper"를 입력하고 액션을 탭하여 추가하세요. 이것은 Left에게 새로운 배경화면 이미지를 생성하도록 요청하는 작업입니다.
  2. "Set Wallpaper Photo"를 다시 검색하고 해당 작업도 추가하세요.
  3. 배경화면 사진 설정 작업에서 대상을 Lock Screen로 설정합니다.
  4. 바로가기가 실행될 때 방해하지 않도록 Show Preview를 끄세요.
  5. Crop to Subject를 끄면 배경화면이 사람이나 사물에 맞게 자동으로 잘리지 않습니다.
  6. 상단에 있는 바로가기 이름을 탭하고 "Left Wallpaper"와 같이 기억하기 쉬운 이름으로 바꾼 다음 완료를 탭합니다.

3단계 - 자동화 생성

바로가기는 무언가가 실행될 때까지 아무 작업도 수행하지 않습니다. 가장 깔끔한 트리거는 일일 시간 기반 자동화입니다.

  1. 바로가기에서 하단의 Automation 탭으로 전환하세요.
  2. + 버튼을 누르고 Time of Day를 트리거로 선택합니다.
  3. 시간을 00:01(자정 1분 후) 또는 원하는 다른 시간으로 설정하세요.
  4. 빈도를 Daily로 설정합니다.
  5. Run 즉시가 선택되어 있는지 확인하고 Notify When Run를 꺼서 매일 알림을 받지 않도록 하세요.
  6. Next를 탭하세요.

4단계 - 바로가기 자동화

  1. 다음 화면에서 2단계에서 만든 바로가기(예: "Left Wallpaper")를 검색하여 선택하세요.
  2. 자동화를 저장하려면 Done를 탭하세요.

그게 다야. 내일 설정한 시간에 iOS가 백그라운드에서 바로가기를 실행하고, Left가 배경화면을 재생성하며, 잠금 화면이 자동으로 새 이미지를 선택합니다.

문제 해결

  • 배경화면이 업데이트되지 않습니다. iOS는 전화기가 뜨겁거나 저전력 모드에 있거나 최근에 잠금 해제되지 않은 경우 백그라운드 자동화를 지연시키는 경우가 있습니다. 전화기를 잠금 해제하면 자동화가 따라잡을 것입니다.
  • "즉시 실행"이 회색으로 표시됩니다. 최신 iOS로 업데이트 - 이전 버전에서는 확인을 위해 탭이 필요했습니다. iOS 17+의 최신 버전은 완전 무인 자동화를 지원합니다.
  • 바로가기는 매번 권한을 요청합니다. 설정 → 바로가기 → "실행 시 표시"가 켜져 있으면 비활성화하세요. 또한 Left 작업이 신뢰할 수 있는 바로가기 작업 아래에 나열되어 있는지 확인하세요.
  • I 하루에 두 번 이상 업데이트되기를 원합니다. 동일한 바로가기를 가리키는 두 번째 자동화를 다른 시간에 생성합니다. iOS는 현재 기본적으로 일일 시간 트리거를 지원하지 않지만 2개 또는 3개를 스택할 수 있습니다.

팁 - 잠금 화면 위젯과 페어링하세요

벨트와 멜빵의 정확성을 위해 배경화면과 함께 잠금 화면에 작은 Left 위젯을 추가하세요. 위젯은 배경화면보다 더 적극적으로 새로 고쳐지므로 배경화면이 몇 시간 뒤쳐져 있어도 항상 최신 번호를 사용할 수 있습니다. 단계는 잠금 화면 위젯 가이드를 참조하세요.
