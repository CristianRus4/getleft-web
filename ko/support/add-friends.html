Left에 친구를 추가하는 방법

Friends는 Left의 소셜 계층입니다. 이는 공개 프로필 네트워크가 아니며 모든 데이터를 표시하지 않습니다. Left의 선택된 부분을 신뢰하는 사람들과 의도적으로 공유할 수 있도록 존재합니다. 친구 추가는 첫 번째 단계일 뿐입니다. 친구가 귀하의 모든 Ahead 날짜, 습관 또는 연속 기록을 자동으로 볼 수는 없습니다. 개별 항목은 나중에 하나씩 공유됩니다.

이 페이지의 내용

  • 1단계 - 로그인
  • 2단계 - Friends 열기
  • 3단계 - 초대 링크 공유
  • 4단계 - 사용자 이름으로 검색
  • 5단계 - 요청 수락
  • 친구들이 당신에게 허락한 것

1단계 - 로그인

Friends에는 Left 계정이 필요합니다.

로그인하지 않은 경우 Friends를 열고 Apple로 로그인을 탭하세요. Settings → Account로 이동하여 로그인를 탭할 수도 있습니다.

로그인하면 다른 Left 사용자가 귀하를 찾을 수 있도록 프로필과 고유한 사용자 이름이 제공됩니다.

2단계 - Friends 열기

Left에서 Friends 섹션을 엽니다. 로그인하면 친구 목록과 + 버튼이 표시됩니다.

+ 버튼을 눌러 친구 추가를 엽니다.

3단계 - 초대 링크 공유

친구 추가에서 Left는 초대 링크를 표시합니다.

다음을 수행할 수 있습니다.

  1. 초대링크를 복사하세요.
  2. 공유버튼으로 공유해보세요.
  3. 메시지, 메일 또는 사용하는 앱을 통해 누군가에게 보내세요.

누군가 귀하의 초대 링크를 열면 Left에서 친구 초대를 보내거나 수락할 수 있습니다.

4단계 - 사용자 이름으로 검색

사용자 이름으로 직접 누군가를 추가할 수도 있습니다.

  1. 친구 추가에서 @사용자 이름로 검색을 탭하세요.
  2. 정확한 사용자 이름을 입력하세요.
  3. Left가 프로필을 찾으면 Invite를 탭하세요.

이미 요청을 보낸 경우 Accept가 대신 표시될 수 있습니다. 이미 요청을 보낸 경우 행에 Pending가 표시됩니다.

5단계 - 요청 수락

수신되는 친구 요청은 Friend Requests에 표시됩니다.

  1. Friends를 엽니다.
  2. 대기 중인 친구 요청이 있는 경우 상단의 사람 배지 버튼을 탭하세요.
  3. Friend Requests에서 Requests 탭을 사용하여 들어오는 요청을 수락하거나 거부합니다.
  4. Pending 탭을 사용하여 보낸 요청을 확인하세요.

공유 초대는 별개입니다. 누군가 연속 기록이나 습관을 보거나 Joint Ahead 데이트에 참여하도록 초대하면 Friends 상단에 종 모양 배지가 나타납니다. 요청를 열려면 탭하세요. 여기서 공유 항목은 공유 연속 및 습관 및 공동 Ahead 날짜 아래에 그룹화됩니다.

친구들이 당신에게 허락한 것

누군가가 친구 요청을 수락한 후 다음을 수행할 수 있습니다.

  1. Joint Ahead 날짜에 초대하세요.
  2. 개인의 습관이나 줄무늬를 관찰하도록 요청하십시오.
  3. 선택한 진행 상황을 확인하고 격려를 보내세요.
  4. 친구가 나와 공유하기로 선택한 경우 해당 친구가 공유한 날짜, 습관, 연속 기록을 확인하세요.

우정만으로는 모든 것을 공개할 수 없습니다. Ahead 날짜, 습관, 연속 기록은 해당 항목을 선택하고 해당 친구를 초대해야만 공유됩니다.
