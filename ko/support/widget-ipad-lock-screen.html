iPad 잠금 화면에 Left 위젯을 추가하는 방법

iPad 잠금 화면 위젯(iPadOS 16 이상에서 사용 가능)을 사용하면 iPad를 깨우는 순간 Left 카운트다운을 확인할 수 있습니다. 잠금 해제가 필요하지 않습니다.

이 페이지의 내용

  • 1단계 - Left에서 이벤트 만들기
  • 2단계 - 잠금 화면 사용자 정의 모드로 들어가기
  • 3단계 - Left 위젯 추가
  • 4단계 - 표시할 이벤트 선택
  • 요구사항
  • 팁: 여러 잠금 화면 프로필

1단계 - Left에서 이벤트 만들기

  1. iPad에서 Left를 엽니다.
  2. +를 눌러 새 이벤트를 생성하거나 기존 이벤트를 편집하세요.
  3. 이름, 날짜 및 표시 스타일(카운트다운, 이후 또는 백분율)을 설정합니다.
  4. 저장를 탭하세요.

2단계 - 잠금 화면 사용자 정의 모드로 들어가기

  1. iPad를 깨우고 잠금 화면으로 이동합니다(잠금 해제하지 않음).
  2. Customise 버튼이 하단에 나타날 때까지 잠금 화면에서 를 길게 누르세요.
  3. Customise를 누른 다음 Lock Screen(왼쪽 패널)를 선택합니다.

3단계 - Left 위젯 추가

  1. 날짜/시계 아래의 위젯 영역을 눌러 위젯 선택기를 여세요.
  2. "Left"를 검색하거나 스크롤합니다.
  3. Left 위젯을 탭하여 잠금 화면 스트립에 추가하세요.
  4. 완료되면 Done를 탭하세요.

4단계 - 표시할 이벤트 선택

  1. 잠금 화면을 다시 길게 누르고 Customise를 탭하세요.
  2. Left 위젯을 탭하여 설정을 엽니다.
  3. 표시하고 싶은 이벤트를 선택하거나 자동 선택을 위해 Smart에 남겨두세요.
  4. 완료를 탭하세요.

요구사항

iPad 잠금 화면 위젯에는 iPadOS 16 이상가 필요합니다. 호환 가능한 iPad 모델에는 iPadOS 16(iPad 5세대 이상, iPad mini 5세대 이상, iPad Air 3세대 이상, 2017년 이후의 모든 iPad Pro 모델)을 지원하는 모든 iPad가 포함됩니다.

팁: 여러 잠금 화면 프로필

iPadOS는 각각 고유한 배경화면과 위젯 세트가 있는 여러 잠금 화면 프로필을 지원합니다. 마감일 카운트다운이 포함된 업무 중심 잠금 화면과 다가오는 휴일이 포함된 개인 잠금 화면을 만들고 잠금 화면 길게 누르기 메뉴에서 전환할 수 있습니다.
