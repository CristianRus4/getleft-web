포커스 모드별로 다른 Left 위젯을 표시하는 방법

iOS 초점 모드를 사용하면 다양한 홈 화면과 잠금 화면 레이아웃 간에 자동으로 전환할 수 있습니다. Work Focus 중에 업무별 Left 카운트다운을 표시하고 나머지 시간에는 개인 카운트다운을 표시하는 방법은 다음과 같습니다.

포커스 모드 + 위젯 작동 방식

iOS의 각 집중 모드(직장, 개인, 수면, 방해 금지 모드 및 사용자 정의 모드)에는 전용 홈 화면 페이지 및 잠금 화면가 있을 수 있습니다. Focus가 활성화되면 iOS는 모든 위젯을 포함하여 해당 레이아웃으로 전환합니다. 즉, Work Focus 홈 화면에 고정된 Left 위젯은 Work Focus 중에만 나타납니다.

1단계 - Left 이벤트 만들기

  1. Left를 열고 상황에 따라 원하는 이벤트를 만듭니다. 예를 들어 업무용으로는 "프로젝트 마감일", 개인용으로는 "휴가" 등이 있습니다.
  2. 각각 Save를 탭하세요.

2단계 - 초점별 홈 화면 페이지 만들기

  1. Settings → Focus로 이동하여 맞춤설정하려는 초점(예: 업무)을 탭하세요.
  2. 화면 사용자 정의를 탭합니다.
  3. 홈 화면에서 Choose를 탭하고 이 집중 중에 표시할 홈 화면 페이지를 선택하거나 특별히 새 페이지를 만듭니다.
  4. 완료를 탭하세요.

3단계 - 각 Focus 홈 화면에 Left 위젯 추가

  1. 집중 모드를 활성화하세요(제어 센터 → 집중 또는 설정에서 예약).
  2. 이 Focus에 할당된 홈 화면 페이지로 이동합니다.
  3. 빈 공간을 길게 누르고 → +를 탭한 후 → Left 위젯을 추가합니다.
  4. 위젯을 길게 누르기 → Edit Widget → 이 Focus와 관련된 이벤트(예: 작업 마감일)를 선택합니다.
  5. 완료를 탭하세요.

4단계 - 각 초점에 대해 반복

개인 초점(또는 다른 것)에 대해서도 동일한 작업을 수행하여 다른 이벤트에서 Left 위젯을 가리킵니다. 이제 Work Focus가 활성화되면 작업 마감일이 표시됩니다. 개인 집중이 활성화되면 휴일 카운트다운이 표시됩니다.

초점별 잠금 화면

특정 잠금 화면(자체 Left 위젯 포함)을 집중 모드에 연결할 수도 있습니다.

  1. 잠금 화면을 길게 누르고 → Customise → 위젯 스트립에 Left를 추가하세요.
  2. Done를 누른 다음 잠금 화면 갤러리 하단에 있는 Focus를 눌러 특정 포커스에 연결하세요.

자동 전환

시간, 위치 또는 앱에 따라 자동으로 활성화되도록 초점 모드를 설정하면 Left 위젯이 수동 작업 없이 컨텍스트를 전환할 수 있습니다. 설정 → 포커스 → [포커스 이름] → 일정 추가로 이동하세요.
