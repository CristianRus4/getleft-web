# Tools group audit (CNTXT-885): 57 tool pages + /tools/ index

Scored 2026-10-21 against facts.json, the built HTML, each page's inline script and `tools/tools.js`. 58 pages. No hard-rule breach found (no Mood, Watch, Mac, price, trial, user-count or "free forever" claim in tool copy; Premium is named correctly on wedding and birthday pages).

**Strong:** the holiday and season pages (Easter, Christmas, New Year, Thanksgiving, Mother's/Father's Day, equinox/solstice) are accurate and deep. I recomputed every date, weekday and rule in them (Easter 2027-31 Western and Orthodox, Thanksgiving, Mothering Sunday, Canadian Thanksgiving, 2027 weekday counts, 100/50-day rules) against the script and all are right. The text matches the code on most utility pages and states its limits honestly.

**Three systemic issues:**
1. **Health and YMYL pages carry unsourced or wrong claims** (life expectancy, pregnancy, fasting x3, sleep). Life expectancy ignores current age when computing years left; the fasting pages state an autophagy/ketosis timeline with no source (a search for human evidence found only generic wellness-site timelines) and call 5:2 a 36-hour fast. None has a medical caveat except sobriety and (partly) life expectancy.
2. **Text and code disagree on four pages** (add/subtract month rule, age month/day rule, ISO week explanation, unix seconds/ms) and one DST bug shifts the pregnancy due date by a day for some LMP dates. These are small fixes in `tools/tools.js` or one sentence each.
3. **Thin conversion and authority layer.** 20 of 58 pages have only the end-of-page CTA, 26 of 57 never link a landing page, none shows a published/updated date or author, and the hard-coded English strings in scripts leave the live ja pages partly English. Rankings are position 55-90 on all but one tool; this is mainly domain authority, so content fixes help but will not move them alone.

Competitor depth: one WebSearch per family (Easter/holiday countdowns, due-date calculators, business days, life expectancy, fasting stages, ISO weeks); results were mostly low-quality pages, so "depth" scores for other families rely on the usual top-result feature set (timeanddate, calculator.net) and are marked unverified. left-time.app queries are widget/app intent ("days left widget", "days since widget") and do not map to the web calculators, so lt_impr is 0 throughout.

Live locales: only `tools/ja` (17 tools + index, 99-100% translated, current). Everything else is English-only.
