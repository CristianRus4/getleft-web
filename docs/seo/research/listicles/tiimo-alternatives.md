# Research: Tiimo alternatives (target keyword "Tiimo alternatives")

Checked 2026-10-20. Primary sources: the US App Store page (`https://apps.apple.com/us/app/id<ID>`, curl) and the iTunes lookup API (`https://itunes.apple.com/lookup?id=<ID>&country=us`), fetched today. Developer sites are labelled "dev site" (secondary). "Not stated" means the source does not say.

Method notes:
- The App Store page shows only the top 10 in-app purchases (IAPs), and the same product name often repeats at different prices. I list them as shown and flag which carry a weekly/monthly/yearly/lifetime label.
- Only the current version's release notes were in the fetched HTML and API, so widget/Live Activity checks cover description plus current release notes.
- Medical, ADHD and "treatment" wording is recorded in a "Listing claims" line for each app. The article must NOT repeat these claims.

## Recommendation

Strongest 6 for an iPhone "Tiimo alternatives" article:

1. **Structured** - the main like-for-like visual timeline planner; free tier with timeline, widgets, Live Activities, Apple Watch (description).
2. **Routinery** - routines that run step by step on timers with a voice; 2 routines free (ad-supported), Apple Watch, widget; 4.7 rating, 18K ratings.
3. **Planny** - Reminders and Calendar on one timeline, Live Activity focus timer; needs iOS 26+; only 44 ratings.
4. **Llama Life** - a countdown timer per task ("timeboxing"); iPhone only; subscription after 7-day trial.
5. **Goblin Tools** - $1.99 app that breaks tasks into steps (Magic ToDo, Estimator); not a visual planner but a common companion; no Apple Watch.
6. **Brili Routines** - visual clock and routine "playlists" with gamified rewards; caveat: last updated 2025-11-25, 603 ratings, no Watch or Mac in compatibility.

Drop and why:
- **Inflow** - sells itself as a "science-based ADHD app" based on "Cognitive Behavioral Therapy (CBT) principles" with coaching tiers up to $199.99; it is a program, not a planner. Highest claim risk.
- **Finch** - a self-care pet app (mood, journaling, quizzes), not a planner or timer; mental-health positioning.
- Others from the brief not fetched because not planners on iPhone: Lunatask, Amazing Marvin, (Not Boring) Habits (not checked), Sorted3 (see `structured-alternatives.md`). Sectograph/Chunk/Brite appear only in WebSearch results; not verified on the App Store.

What people search this for (WebSearch "Tiimo alternatives", 2026-10-20):
- Third-party lists (habi.app, alternativeto.net, britetodo.com via search summaries) say Tiimo is "one of the pricier planners" and lacks Android, Windows or Web. Caution: Tiimo's own site (tiimoapp.com) now states it is "Available on iOS, iPadOS, watchOS, Android & Web", so the platform complaint looks out of date. Sources: https://habi.app/insights/tiimo-alternatives/ , https://alternativeto.net/software/tiimo/ , https://britetodo.com/alternatives-to-tiimo (competitor-run; search summaries only, not fetched).
- Lists name Structured, Routinery, Goblin Tools, Llama Life, Brili, Brite, Sectograph. Price is the only reason these sources state; Tiimo's listing shows Pro from $7.00 to $54.00 entries (periods not labelled).
