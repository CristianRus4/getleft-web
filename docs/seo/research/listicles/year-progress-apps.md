# Year-progress apps: research sheet

Target queries: "year progress app" / "year progress widget". All facts come from sources fetched on **2026-10-20**: the US App Store page (`https://apps.apple.com/us/app/id<ID>`) and the iTunes lookup API (`https://itunes.apple.com/lookup?id=<ID>&country=us`). "Not stated" means the listing does not say. It is not a claim the feature is absent.

## Recommendation

Caveat: the category is almost all micro-apps. Searching "year progress" returns about 25 apps, and apart from Countdown - Pretty Progress, none have more than 33 ratings.

**Include (5):**
1. **Countdown - Pretty Progress** (3,109 ratings, 4.71, updated 2026-10-18). Only one with real volume. Default yearly/monthly/weekly/daily progress, Home/Lock/StandBy/Watch. General countdown app, not year-only.
2. **Year Progress: Widget** (3 ratings, updated 2026-02-28). The most complete pure year-progress app on paper: wallpaper generator, Lock/Home widgets, Watch complications.
3. **Orbit: Year Progress & Life** (11 ratings, 4.91, updated 2026-10-09). Added from search. 10 year-progress styles, one-time $4.99, Data Not Collected.
4. **Life Dots: Visualize Time** (33 ratings, 4.97, updated 2026-09-29). Added from search. Free, no IAP, dots for day/month/year/lifespan, widgets.
5. **Life Widget - Time Progress** (30 ratings, 4.03, updated 2026-09-18). Widgets on Home, Lock and Watch, but the listing never mentions year progress; include only as a "life progress" option.

**Drop:**
- **Day Dial - Year Progress Bar**: last updated 2025-04-08 (over 18 months), 6 ratings.
- **Year Progress: Life in Motion**: last updated 2025-04-20, 5 ratings, tracking label.
- **365days - track year progress**: last updated 2023-07-30, one-line listing.
- **Year Percent**: 0 ratings, version 1.0 from 2025-08-13.

**Own app:** search for "year progress" returned **Left: Widgets for Time Left** (6740155884, Cntxt Limited), 450 ratings, 4.57, updated 2026-10-11. That is the site's own app; it is documented at the end for reference and is not a competitor.

**Availability:** all IDs resolved on the US store. None missing.

**Not fetched, seen in search only (names, counts, dates from today's search API):** Year Progress (6759851729, 0 ratings), This Year Progress 2026 (0), TimeDot (0), Year Progress Diary 365 Dots (1), TimeFlow: Year Progress (10 ratings, last update 2025-04-29), Pixa - My Year in Pixels (1,931 ratings; a mood/year-in-pixels diary, off-topic).
