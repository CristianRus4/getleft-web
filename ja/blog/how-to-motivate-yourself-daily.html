毎日自分を奮い立たせる方法（やる気が出ないときに）

更新：2026年11月12日 · 読了時間9分

モチベーションに関するアドバイスの多くは、始める前に準備ができたと感じる必要がある、と前提しています。だから気持ちが来るのを待ちます。ぴったりのプレイリスト、ぴったりの気分、新しい月曜日。来る日もあります。でもたいていは来なくて、やるつもりだったことは明日に持ち越されます。

もっと役に立つ見方があります。モチベーションは、たいてい始める前ではなく、始めたあとにやってきます。見つけるものではありません。始めるのが簡単になる条件を整えれば、気持ちはあとからついてくることが多いのです。このガイドでは、毎日の4つのステップのループ、調子の悪い日や悪い週のための計画、今日からiPhoneで設定できる2分間の朝と夜の習慣を紹介します。

行動が先、モチベーションはあとから追いつく

気が進まなかったのに、10分後には楽しんでいた散歩や、気が重かったのに4分で終わったメールを思い浮かべてみてください。抵抗は、ほぼすべて、始める前の隙間にあります。動き出せば、タスクは具体的になり、具体的なタスクは、想像していたものより小さく感じられます。

だから、「どうやってやる気を出そう？」と問うのはやめて、「どうすれば、始めるのがあまりに簡単で、とにかくやってしまうようにできるか？」と問いましょう。目に入るもの、最初の一歩の大きさ、終えたあとに起きること、そしてそれが大事な理由は、変えられます。これが、ループの4つの要素です。

ここで扱うのは、毎日の始め方、つまり今日の分を動かし始めることです。数か月にわたって目標を生かし続けるのが悩みなら、もっと長期戦の話を意志力に頼らず目標を継続するコツのガイドで解説しています。

毎日のループ：4つの要素

1. 見逃せないきっかけ

良い意図の多くは、怠けているからではなく、ちょうどいい瞬間に思い浮かばないから消えてしまいます。向こうから見つけてくれるきっかけが必要です。ロック画面は理想的です。どうせ1日に何十回も見ますから。そこに、本当に大切なものを置きましょう。

  • 楽しみにしていることへのカウントダウン。旅行、レース、誕生日、講座が終わる日。「18日」は、カレンダーの予定とは違って、その日へと引っ張ってくれます。
  • 残りが減っていく1年や1週間。1年がもう86%過ぎたことや、もう木曜日だとわかるのは、小言ではなく、やさしい後押しになります。なぜこれが多くの人に効くのかは、年の進捗とは何かの解説で説明しています。
  • 1つの目標の進み具合。「300kmのうち142km」や「24冊のうち11冊」なら、今の位置が正確にわかり、次の小さな一歩がはっきりします。

1つか2つを選びましょう。5つの数字が並んだロック画面は、読まなくなる壁紙になってしまいます。

2. いちばん悪い日でもできる、小さな第一歩

毎日の行動には、2分間バージョンが必要です。疲れていても、忙しくても、気分が沈んでいてもできる、いちばん小さな一部分。理想のバージョンではなく、最低ラインです。

  • 5km走る → ランニングシューズを履いて、外に一歩出る。
  • 1時間勉強する → ノートを開いて、1ページ読む。
  • 500語書く → 1文書く。
  • 家を片づける → 1つの面を片づける。

普通の日は、2分間バージョンから始めて、そのまま続けます。たいていはそうなります。調子の悪い日は、それをやって終わりにしても、ちゃんとカウントされます。これが大事です。小さいバージョンがカウントされないと、脳はそれがごまかしだと学習し、もうだまされなくなります。

3. 1日の終わりに、進歩の証拠を残す

モチベーションは、証拠を糧にします。昨日の努力がどこかにつながったと見えれば、今日の始まりが無意味に感じにくくなります。努力が跡形もなく消えてしまうと、明日それを気にかけるのは難しくなります。

だから、毎日の終わりに、10秒のログで締めくくりましょう。習慣にチェックを入れ、ページ数やkmを追加します。数週間たてば、反論しようのない記録ができ、「自分は何もしていない」と感じる日にこそ、それが必要です。

4. 自分だけの理由

「運動すべき」は、誰かから借りてきた理由です。「7月に、ビーチで子どもたちについていきたい」は、あなた自身の理由です。借りた理由は、週の半ばには擦り切れます。自分の理由は、特に日付や人と結びついていれば、長持ちします。

毎日の行動ごとに、次の文を完成させてみましょう。「[日付]までに、[大切な人やもの]のために、これをしている…」。そして、理由をきっかけとつなげます。理由が7月の休暇なら、ロック画面のカウントダウンは、その休暇にします。こうすれば、スマートフォンを見るたびに、行動と理由が同時に思い出されます。

iPhoneでループを設定する

紙とカレンダーでも作れます。スマートフォンなら、きっかけが自動になります。多くの人が苦労するのは、そこです。4つの要素が、私たちが作っているアプリLeftでどう対応するかを紹介します。

  • きっかけ：楽しみにしていることへのAheadカウントダウンを、ロック画面ウィジェットとして置きます。各カウントダウンは、残り時間と、設定した日からの進捗バーを表示します。または無料のLeft壁紙を使うと、短いショートカットのオートメーションで、毎日自動で更新される、1年または人生のグリッドが、ロック画面になります。
  • 第一歩：2分間バージョンの名前をつけた習慣（「靴を履く」「1ページ」）。チェックするのは最低ラインだけなので、調子の悪い日でもカウントされます。
  • 証拠：習慣とAim。Aimは、読んだ本の冊数や走った距離など、目標値のある、数えられる目標です。ワンタップで記録するか、数量を入力すると、進捗の履歴が残ります。
  • 理由：日付はAheadに入れます。カウントダウン、習慣、Aimをウィジェットで並べて置けば、行動と理由が同じ画面に収まります。

Leftには、ホーム画面とロック画面のウィジェットがたくさんあり、習慣ウィジェットは、今日まだチェックしていないものを表示します。ほかのレイアウトは、画面全体で目標を視覚的に追跡する方法のガイドで紹介しています。

Set up your daily cue

2分間の朝と、2分間の夜

普通の日に、このループがどう見えるかを紹介します。目標は1つ、今年24冊の本を読むことです。

朝（2分間）

  1. ちらっと見る。スマートフォンを手に取ります。ロック画面には、残り2か月を切った年グリッドと、「本：24冊のうち19冊」のウィジェットが表示されています。アプリを開く必要も、何かを決める必要もありません。
  2. 第一歩を選ぶ。今日の「1ページ」をいつやるか決めます。すでにしていることに結びつけましょう。最初のコーヒーのとき、電車の中、昼にメッセージを確認する前など。
  3. できるなら、やってしまう。今2分あるなら、今そのページを読みます。朝に、たとえ少しでも始めておくと、1日の残りの重荷が軽くなります。

夜（2分間）

  1. 未チェックを確認する。習慣ウィジェットに、「1ページ」がまだ残っているかが表示されます。残っていれば、ベッドで1ページ読みます。必要なのは、それだけです。
  2. 証拠を記録する。習慣にチェックを入れます。1冊読み終えたなら、Aimにワンタップで記録して、数字が動くのを見届けましょう。
  3. 明日の第一歩を用意する。本を枕の上に、靴を玄関に、ノートを開いて机の上に置いておきます。明日の2分間は、今夜から始まっています。

朝が全般的に苦手なら、ADHDに優しい朝のルーティンと組み合わせるとよく合います。3つの小さなステップ、目に見えるきっかけ、順番にこだわらないやり方です。

調子の悪い日のプラン

朝からぐったりしている日もあります。そんな日がどんなものか、あらかじめ決めておきましょう。そうすれば、エネルギーがいちばん低いときに、自分と交渉せずに済みます。

  • 名前をつける。「調子の悪い日」。はっきり言葉にすると、余計な罪悪感が取れます。
  • 最低ラインまで下げる。今日は2分間バージョンだけ。フルのワークアウトも、1時間の勉強もなし。
  • 全部ではなく、1つを選ぶ。毎日の習慣が3つあるなら、いちばん大事な1つを選び、ほかは抵抗せずに手放します。
  • それでも記録する。調子の悪い日にチェックした最低ラインは、見た目以上の価値があります。「ちゃんと現れる人」という自分像が保たれます。

1週間、何をやってもうまくいかないとき

ループが1週間まるごと動かなかったとしても、それは情報であって、自制心への判決ではありません。次の順に確認してみましょう。

  1. きっかけは、まだ目に入るか？数週間たつと、同じウィジェットは目が素通りするようになります。移動する、サイズを変える、カウントダウンを新しいものに替えるなどしましょう。
  2. 第一歩は、まだ小さいか？「1ページ」が、いつのまにか「1章」に育っていませんか。小さく戻しましょう。
  3. 理由は、今も本当か？旅行が中止になったり、目標が合わなくなったりしたのかもしれません。理由を変えるか、放置して腐らせるのではなく、意図的に目標を手放しましょう。
  4. 単純に、今は生活が詰まっているだけでは？病気、引っ越し、新しい赤ちゃん、試験期間。毎日失敗するより、再開日を決めて、一定期間、習慣を一時停止しましょう。

やる気の低下が何週間も続き、あらゆることに広がり、睡眠の質の低下や、普段なら楽しめることへの興味の喪失を伴うなら、モチベーションの問題にとどまらないかもしれません。医師やほかの医療専門家に相談するいい機会です。アプリは1日の組み立てを助けられますが、治療ではありません。

ごほうびとストリーク：役に立つ人と、逆効果になる人

ストリークと小さなごほうびは、目に見えない努力を見えるものに変えます。多くの人にとって、上がっていく数字だけで動き出すきっかけになります。でも、誰にでも向くわけではないので、自分がどちらに傾くかを知っておく価値があります。

役に立ちやすいのは、こんなとき：

  • 数字が上がっていくのを見るのが好きで、できなかった日があっても気分が崩れない。
  • ごほうびが小さく、行動の直後にもらえる。数週間後ではない。
  • 記録しているのが、デンタルフロスや新しい運動習慣のように、まだ楽しめていないこと。

逆効果になりやすいのは、こんなとき：

  • ストリークが借金になる。90日目になると、習慣が怖くなります。連続記録を途切れさせるほうが、サボるより悪く感じるからです。もう、数字を守っているだけで、そのことをやっているわけではありません。
  • ゼロか百かで考える。1回できなかっただけで、努力全体が失敗した証拠のように感じ、すっかりやめてしまいます。
  • その活動をすでに楽しんでいる。趣味の読書のように、好きなことを、点数のつくタスクに変えると、宿題のように感じられることがあります。

ストリークが逆効果になるなら、連続記録ではなく、合計を記録しましょう。「今年の本の冊数」や「今月のkm」を数えるAimなら、1つ1つの行動が報われ、ゼロにリセットされることもありません。ストリークが役に立つなら、後押しが必要な1〜2つの習慣に使いましょう。設定の方法と、途切れたときの対処は、ストリークの作り方のガイドをご覧ください。

質問

何もする気が起きないとき、どうやって自分を奮い立たせればいいですか？

気持ちを待たないでください。1つのタスクの2分間バージョンをやって、それを勝利として数えましょう。モチベーションは、たいてい始めてからやってきます。来なくても、何かはやったことになります。

毎日、午後になるとやる気がなくなるのはなぜですか？

たいていは、実際のその日に対して、計画が大きすぎたのです。第一歩を早めにやり、夜のタスクは、疲れていても終えられる2分間の最低ラインにしましょう。

自制心とモチベーション、どちらに頼るほうがいいですか？

どちらも、毎日は持ちません。目に見えるきっかけ、小さな第一歩、手早い記録という小さなルーティンなら、自制心もモチベーションも低い日に機能します。

毎日の習慣は、いくつ記録すべきですか？

1〜3つから始めましょう。それ以上だと、夜の記録が雑用に感じられ、ロック画面のきっかけもごちゃごちゃします。最初のものが苦労なく回るようになってから、次を加えましょう。

通知なしで、iPhoneにやる気を保つリマインドをさせられますか？

はい。ロック画面ウィジェットや、1年やカウントダウンを表示する壁紙なら、どうせ見る場所にきっかけを置けるので、スマートフォンを手に取るたびに、別の通知なしで後押しが得られます。
