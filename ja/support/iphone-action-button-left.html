iPhone Action Button で Left を開く方法

iPhone 15 Pro、iPhone 16、およびそれ以降のモデルの Action Button は、Left を直接開くショートカットを含むショートカットを実行するように割り当てることができます。設定方法は次のとおりです。

必要なもの

  • iPhone 15 Pro / Pro Max または iPhone 16 シリーズ以降 - Action Button はこれらのモデルで利用可能です
  • 左がiPhoneにインストールされています
  • ショートカット アプリ - iOS に組み込まれており、ダウンロードは必要ありません

ステップ 1 - Left を開くショートカットを作成する

  1. ショートカット アプリを開きます。
  2. + ボタンをタップして、新しいショートカットを作成します。
  3. アクションの追加をタップし、「アプリを開く」を検索します。
  4. アクションの App フィールドをタップし、Left を選択します。
  5. 上部のショートカット名をタップし、名前を「"Open Left"」などに変更します。
  6. 「完了」をタップします。

ステップ 2 - ショートカットを Action Button に割り当てる

  1. 「設定」→「アクションボタン」を開きます。
  2. 「Shortcut」に到達するまでオプションをスワイプします。
  3. ショートカットを選択をタップし、作成したばかりの「Leftを開く」ショートカットを選択します。
  4. 設定を終了します - これで、Action Button が設定されました。

ステップ 3 - テストする

アクション ボタン (iPhone の左上端にあるボタン) を押し続けます。 Left は、ロック画面からでもすぐに開くはずです。

詳細: 特定の Left イベントを開く

Left が URL スキームのディープ リンクをサポートしている場合は、特定のイベントを直接開くことができます。利用可能な URL アクションと、アプリのメイン画面ではなく名前付きイベントを開くショートカットの作成方法については、左のショートカット ガイドを確認してください。

その他の便利な Action Button 割り当て

Action Button は一度に 1 つの割り当てをサポートしますが、 メニューのショートカット を使用して複数のオプションを表示できます。いくつかのオプション (Left を開く、タイマーの開始、ミュート) をリストした「メニューから選択」アクションを含むショートカットを作成します。その後、Action Button を押すたびにピッカーが表示されます。
