常見問題

可以離線使用嗎？我的資料是私人的嗎？

小部件完全離線工作。您的習慣、日期和設定會保存在您的裝置上，並透過 iCloud 同步（如果啟用）。共同的習慣和聯合倒數計時透過您的 Left 帳戶同步。有關完整詳細信息，請參閱 隱私權政策。

Left 會耗盡我的電池嗎？

不會。 Left 沒有持久的後台進程。小部件由 iOS 按照系統控制的時間表呈現 - Left 不會在刷新之間在背景運行。電池影響可以忽略不計。

如何新增重複事件？

在 Left 中建立或編輯事件時，點擊 Repeat 選項並選擇重複週期 - 每天、每週、每月或每年。每次發生後倒數都會自動重置。

我可以與其他人分享活動嗎？

是的－Left支援與好友聯合倒數計時。兩人都需要一個Left帳號。前往 Friends 部分，透過使用者名稱新增您的朋友，然後一起建立共享活動。你們都會看到相同的倒數計時。

預期壽命是如何計算的？

Left 使用基於年齡、性別、國家/地區以及可選健康和活動因素的估計值。您可以在應用程式中調整您的使用壽命設定。有關方法，請參閱 預期壽命計算器 。

我在 Friends 清單中看不到我的朋友

你們倆都需要登入 Left 帳號。透過 Friends 部分的使用者名稱發送好友請求，並讓他們接受。一旦你們成為朋友，就可以聯合倒數和 Shared Since。

Left Wallpaper 沒有更新

Left Wallpaper透過Apple Shortcuts更新。開啟捷徑應用程式並確認 Update Left Wallpaper 自動化已啟用。當設備很熱或處於低功耗模式時，iOS 可能會延遲自動化。

Left 小工具是免費的嗎？

是的。 Time Left、超過20個小部件、你、桌布、Friends、Time Between、遊戲和其他核心工具永久免費。

Left 支援哪些小工具尺寸？
  • 主畫面：小（2×2），中（4×2），大（4×4），iPad上超大（8×4）
  • 鎖定畫面：矩形（時鐘下方）與圓形（時鐘上方）
  • StandBy：全螢幕小工具堆疊
  • Mac：中小型Notification Center和桌面上
如何將小工具新增到主畫面？
  1. 觸摸並按住主螢幕，直到應用程式抖動。
  2. 點擊 +（左上角）並搜尋 Left。
  3. 選擇尺寸，點選「新增小工具」。
  4. 長按小工具 → Edit Widget 選擇要顯示的事件。

請參閱完整的 主螢幕小工具指南 以取得螢幕截圖。

如何新增鎖定畫面或 StandBy 小工具？
  1. 長按鎖定畫面並點選 Customize。
  2. 點選時鐘下方的小工具條，選擇 Left。
  3. 點選 Done。

對於 StandBy：在 StandBy 中長按小工具堆棧，點選 +，然後新增 Left。請參閱 StandBy 指南 。

小部件中的時間是如何計算的？

Left 計算從當前時刻到您當地時區的目標日期的時間。每次小部件刷新時，倒數計時都會更新（通常每 15-30 分鐘一次），並在您開啟應用程式時立即刷新。

我可以只顯示天數而不是天+小時+分鐘嗎？

是的。編輯小工具時（長按 → 編輯小工具），您可以選擇顯示樣式 - 僅天、天和小時、完整細分或百分比。可用選項取決於小部件的大小。

百分比視圖顯示什麼？

百分比視圖顯示一個時間段已經過了多少時間。例如，如果您正在追蹤年份，它會顯示該年已經過去了多少百分比。對於倒數計時事件，它顯示建立日期和目標日期之間已經過去了多少時間。

Left 沒有出現在我的小工具清單中
  1. 安裝後至少開啟一次 Left 應用程式。
  2. 更新到最新的iOS/iPadOS和最新版本的Left。
  3. 重新啟動您的裝置並嘗試再次新增小工具。
為什麼小部件不更頻繁地刷新？

iOS 管理小工具刷新預算以保護電池。開啟 Left 會立即刷新所有小工具。否則，系統會安排大約每 15-30 分鐘刷新一次。這是適用於所有應用程式的 iOS 約束。

我的小部件為空或顯示載入狀態
  1. 開啟 Left — 這會強制立即重新載入小工具。
  2. 刪除該小部件並重新新增它。
  3. 檢查設定 → Left → 背景應用程式重新整理已啟用。
  4. 如果處於低功耗模式，小部件刷新頻率會降低 - 這是預期的。
小部件卡住，顯示舊日期

開啟 Left 應用程式一次即可強制刷新。如果小部件仍然顯示過時的日期，請刪除並重新添加它 - 這會將小部件的資料連接重設為 Left。

為什麼小部件不顯示秒數？

iOS 不允許主螢幕小工具顯示即時秒數 - 它們只能定期更新。鎖定螢幕小工具也遵循此限制。如需即時倒數計時，請直接開啟 Left 應用程式。

Left Premium 裡面有什麼？什麼是免費的？

Time Left、超過20個小部件、你、桌布、Friends、Time Between、遊戲和其他核心工具永久免費。 Left Premium 解鎖了更深入的方式來追蹤習慣、連續記錄、特殊日期和您的一天。

如何恢復Left Premium？

開啟 Left → 設定 → 恢復購買 。確保您使用用於訂閱或終身購買的相同 Apple ID 登入。

Left Premium 是否適用於我的所有裝置？

是的。 Left Premium 與您的 Apple ID 綁定，而不是單一裝置。在登入相同 Apple ID 的任何裝置上，點擊 Left 設定中的恢復購買即可解鎖進階功能。

Left Premium適用於Family Sharing嗎？

終身購買可能符合 Family Sharing 的資格，具體取決於 Apple 的購買設定。確保在您的 Apple ID 設定中啟用 Family Sharing，並且為您的家庭群組開啟「共享購買」。

我的習慣是不同步到我的 iPad/其他設備
  1. 確保兩台裝置都登入同一個 iCloud 帳戶。
  2. 在設定 → Apple ID → iCloud → 顯示全部 → Left 中檢查是否為 Left 啟用了 iCloud Drive。
  3. 在遺失資料的裝置上開啟 Left — 同步在啟動時運作。
  4. 稍等片刻，然後下拉刷新事件清單。
如何在新設備上恢復我的資料？

在新裝置上登入相同的 Apple ID 和 iCloud 帳戶，然後安裝 Left。首次啟動時，Left 將自動同步您來自 iCloud 的活動和習慣。這可能需要一些時間，具體取決於您的連線速度。

如何匯出或備份我的活動？

如果啟用同步，您的事件將儲存在 iCloud 中，這將作為您所有裝置上的自動備份。目前沒有手動匯出功能。如果 iCloud 同步關閉，資料僅存在於您的裝置上。

我可以在沒有 Apple ID 或 iCloud 的情況下使用 Left 嗎？

是的。 Left 在沒有 iCloud 的裝置上工作。您可以使用核心應用程序，無需跨裝置同步。分享功能使用您的免費 Left 帳戶，Apple 裝置之間的自動同步需要 iCloud。
