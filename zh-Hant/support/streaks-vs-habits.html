條紋與習慣

Since 是 Left 的一部分，用於追蹤已經開始的時間。您可以在這裡保存想要保護的連續記錄、想要養成的習慣以及想要衡量的目標。連勝、習慣和目標都可以幫助您了解進展情況，但每個都回答不同的問題。

什麼是連勝？

連續紀錄會進行事件計時，追蹤從起始點或上次重設以來的時間。在您重設之前，它會自動持續增加。

連續使用不需要您每天點擊的東西。例如：

  1. 不喝酒的日子。
  2. 距離你們開始戀愛關係已經過了幾天。
  3. 距離您搬到新城市已有幾天了。
  4. 距離您開始個人挑戰已有幾天了。

關鍵思想是計數器保持自身運作。如果連續結束，您可以重新啟動或重置計數器。

什麼是習慣？

習慣會追蹤您需要完成的重複操作。您可以選擇該習慣發生的頻率，然後在執行時將其標記為完成。

習慣可以是每天、每週、每月或安排在特定日期。有些習慣也可能需要在同一時期內完成多個習慣。例如：

  1. 每天喝水 4 次。
  2. 每週去健身房 3 天。
  3. 每個工作日都閱讀。
  4. 每月審查一次財務狀況。

如果你沒有在規定的時間完成這個習慣，那麼這個習慣就會被打破。

他們如何在Since一起生活

開啟Since並點選+按鈕。您可以選擇目標、新增連續記錄或新增習慣。

目標、連勝和習慣出現在同一個 Since 區域，因為它們都是關於已經開始的進展。您可以根據您想要關注的內容過濾視圖。

範本可用，因此您並不總是需要從空白項目開始。目標模板對於基於數字的目標非常有用，連勝模板對於有意義的生命計數器非常有用，而習慣模板對於具有時間表、提醒和完成目標的例程非常有用。

何時使用每一項

選擇一個連續時間，除非您重置它，否則事情應該會自動繼續。連續記錄最適合「自從…以來多久」的追蹤。

當您需要採取行動時選擇一個習慣並將其標記為完成。習慣對於日常工作來說是最好的，Left 應該知道你是否完成了今天、本週或本月的工作。

當目標是用您想要增加或減少的數字來衡量時，請選擇目標。目標最好是「多少？」諸如省錢、讀的書、跑的公里數、減少債務或學習的時間等目標。

例如，「不喝酒的天數」可以很好地作為連續記錄，因為它會一直計數，直到您重新啟動為止。 「去跑步」作為一種習慣效果更好，因為你需要在計劃的日子裡完成它。 「今年跑500公里」作為目標效果更好，因為目標是一個數字。

僅限習慣的功能

有些功能是特定於習慣的，因為習慣有完成數據：

  1. 習慣強度洞察顯示了習慣的一致性。
  2. 習慣時間表控制何時會出現該習慣。
  3. 當一個習慣需要多次完成時，可以追蹤多次完成情況。
  4. 取得最後一次提醒如果習慣仍未完成，可以在一天結束時提醒您。
  5. 以今天為中心的視圖可以顯示待處理、部分、已完成或錯過的習慣進度。

條紋有其自身的優點：它們簡單、自動，非常適合有意義的計數器，無需每日記錄即可繼續移動。
