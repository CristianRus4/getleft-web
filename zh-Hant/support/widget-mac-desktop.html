如何在 Mac 桌面上新增 Left 小工具

macOS Sonoma 引入了直接位於桌面上的互動式小工具 - 在您的應用程式視窗後面始終可見。以下是如何將 Left 放在 Mac 桌面上。

要求

  • macOS Sonoma (14) 或更高版本 — 桌面小工具是 Sonoma 的一項功能
  • Left 安裝在 Mac 上 — 在 Mac App Store 上搜尋“Left”

步驟 1 — 在 Mac 上安裝 Left

Left 是通用購買 — 如果您在同一 Apple ID 下的 iPhone 或 iPad 上擁有它，則可以從 Mac App Store 在 Mac 上下載它，無需額外費用。開啟Mac應用程式商店並搜尋「Left」。

步驟 2 — 右鍵點選桌面新增小工具

  1. 點擊 Mac 桌面的空白區域以確保沒有應用程式處於焦點。
  2. 右鍵點選桌面上的 （或按住 Control 鍵點選）。
  3. 從上下文選單中選擇 Edit Widgets…。

步驟 3 — 尋找並新增 Left

  1. 在向上滑動的小部件編輯器中，搜尋 "Left" 或捲動到它。
  2. 點擊 Left 小工具上的 + 按鈕將其新增至桌面，或將其拖曳到特定位置。
  3. 點選 Done。

步驟 4 — 配置小工具

  1. 右鍵點選桌面上的 Left 小工具。
  2. 選擇 Edit Widget。
  3. 選擇要顯示的事件，或使用 Smart 進行自動選擇。
  4. 按 Esc 鍵或點選其他位置進行儲存。

移動桌面小部件並調整其大小

  • 按一下並拖曳桌面小工具以將其重新放置在桌面上的任意位置。
  • macOS Sonoma 中的桌面小部件有小型和中型尺寸 - 刪除並重新添加以更改尺寸。
  • 小部件位於應用程式視窗後面，當您顯示桌面時（用四根手指在觸控板上向上和向外滑動，或按 Mission Control），小部件就會變得可見。

小工具互動性

在 macOS Sonoma 及更高版本中，桌面小部件是互動的 - 您可以單擊 Left 小部件直接打開 Left 應用程序，而無需在 Dock 或應用程式資料夾中找到它。
