如何用iPhone Action Button開啟Left

iPhone 15 Pro、iPhone 16 及更高版本上的 Action Button 可以指定運行快捷方式 - 包含直接開啟 Left 的捷徑。設定方法如下。

你需要什麼

  • iPhone 15 Pro / Pro Max 或 iPhone 16 系列或更高版本 — Action Button 適用於這些型號
  • Left 安裝在您的 iPhone 上
  • 捷徑應用程式 — 內建於iOS中，無需下載

步驟 1 — 建立一個開啟 Left 的捷徑

  1. 開啟 Shortcuts 應用程式。
  2. 點選 + 按鈕建立新捷徑。
  3. 點選新增操作，然後搜尋「開啟應用程式」。
  4. 點選操作中的 App 字段，然後選擇 Left。
  5. 點擊頂部的捷徑名稱，並將其重新命名為 "Open Left"。
  6. 點選 Done。

步驟 2 — 將捷徑指派給 Action Button

  1. 開啟設定→操作按鈕。
  2. 滑動選項，直至到達 Shortcut。
  3. 點擊 選擇捷徑 並選擇您剛剛建立的 「開啟 Left」 捷徑。
  4. 退出設定 — Action Button 現已配置完成。

第 3 步 — 測試

按住 A 操作按鈕 （iPhone 左上角的按鈕）。 Left 應該立即打開，即使是從鎖定畫面也是如此。

進階：開啟特定的 Left 事件

如果Left支援URL方案深度鏈接，則可以直接開啟特定事件。檢查 Left 捷徑指南 以了解可用的 URL 操作以及如何建立開啟命名事件而不是應用程式主畫面的捷徑。

其他有用的 Action Button 作業

Action Button 支援一次一項分配，但您可以使用 選單捷徑 來呈現多個選項。使用「從選單中選擇」操作建立一個快捷方式，列出多個選項（開啟 Left、啟動計時器、靜音）—然後，每次按下 Action Button 時都會顯示一個選擇器。
