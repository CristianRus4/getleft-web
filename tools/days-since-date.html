How this days since calculator works

Enter the date and optional time of an event, and the calculator subtracts it from the current moment. The result updates automatically so you can see the exact number of days since the event began.

This is useful for anniversaries, sobriety dates, streaks, product launches, recovery timelines, and any milestone where the elapsed time matters.

A worked example

Say a streak started on January 1, 2026 at 9:00. On November 10, 2026 at 9:00, exactly 313 days have passed. That is 44 full weeks, about 10 months, and 7,512 hours. One minute earlier, at 8:59, the count still shows 312 days.

When the count goes up

The tool counts full 24-hour periods from the start time. With the default start time of 9:00, the day count goes up at 9:00 each morning, not at midnight. On the start day itself the count is 0, and it becomes 1 once a full day has passed. To count calendar days, so the number changes at midnight like a date on a calendar, set the start time to 00:00.

Days, weeks and months

Weeks are full 7-day periods. Months are an estimate: the tool divides the days by 30.44, the average month length, because calendar months run from 28 to 31 days. For an exact answer in years, months and days, enter your start date in the age calculator, which does the calendar arithmetic.

Common ways to use days since

People often search for days since a birthday, days since a breakup, days since quitting a habit, or days since a project started. The same calculation works for all of them: pick the start date and the elapsed count becomes visible.

In Left, this maps closely to Since and streak tracking. Once you know the date, you can keep it visible on your iPhone widget instead of recalculating it.

Date and time accuracy

The calculator uses your local browser time zone. If the original event happened in another time zone, enter the equivalent local date and time for the most accurate count.

Daylight saving can move the moment the count goes up by an hour. If the clocks are an hour ahead of where they were on your start date, summer time now and winter time then, the count goes up an hour later on the clock than your start time. In the opposite case it goes up an hour earlier.

To keep the count on your Home Screen, use the Left days since widget.

Questions

How many days has it been since a date?

Enter the date above, and a start time if you know it. The tool shows the full days, weeks, months and hours that have passed and updates every minute.

Does the count include the start day?

No. On the start day the count is 0, and it becomes 1 once a full day has passed. Add 1 if you want the start day to count as day 1.

Why does the day count change at 9:00 and not at midnight?

The tool counts full 24-hour periods from the start time, which is 9:00 by default. Set the start time to 00:00 and the count changes at midnight.

Which time zone does it use?

Your device's time zone. If the event happened somewhere else, enter its date and time converted to your local time.

Can I enter a future date?

A future date shows "Not yet". To count the days to a date ahead, use the date countdown calculator.
