常见问题

可以离线使用吗？我的数据是私人的吗？

小部件完全离线工作。您的习惯、日期和设置会保存在您的设备上，并通过 iCloud 同步（如果启用）。共同的习惯和联合倒计时通过您的 Left 帐户同步。有关完整详细信息，请参阅 隐私政策。

Left 会耗尽我的电池吗？

不会。Left 没有持久的后台进程。小部件由 iOS 按照系统控制的时间表呈现 - Left 不会在刷新之间在后台运行。电池影响可以忽略不计。

如何添加重复事件？

在 Left 中创建或编辑事件时，点击 Repeat 选项并选择重复周期 - 每天、每周、每月或每年。每次发生后倒计时都会自动重置。

我可以与其他人分享活动吗？

是的——Left支持与好友联合倒计时。两人都需要一个Left账户。转到 Friends 部分，通过用户名添加您的朋友，然后一起创建共享活动。你们都会看到相同的倒计时。

预期寿命是如何计算的？

Left 使用基于年龄、性别、国家/地区以及可选健康和活动因素的估计值。您可以在应用程序中调整您的使用寿命设置。有关方法，请参阅 预期寿命计算器 。

我在 Friends 列表中看不到我的朋友

你们俩都需要登录 Left 帐户。通过 Friends 部分的用户名发送好友请求，并让他们接受。一旦你们成为朋友，就可以联合倒计时和 Shared Since。

Left Wallpaper 没有更新

Left Wallpaper通过Apple Shortcuts更新。打开快捷方式应用程序并确认 Update Left Wallpaper 自动化已启用。当设备很热或处于低功耗模式时，iOS 可能会延迟自动化。

Left 小部件是免费的吗？

是的。 Time Left、超过20个小部件、你、壁纸、Friends、Time Between、游戏和其他核心工具永久免费。

Left 支持哪些小部件尺寸？
  • 主屏幕：小（2×2），中（4×2），大（4×4），iPad上超大（8×4）
  • 锁屏：矩形（时钟下方）和圆形（时钟上方）
  • StandBy：全屏小部件堆栈
  • Mac：中小型Notification Center和桌面上
如何将小部件添加到主屏幕？
  1. 触摸并按住主屏幕，直到应用程序抖动。
  2. 点击 +（左上角）并搜索 Left。
  3. 选择尺寸，点击“添加小部件”。
  4. 长按小部件 → Edit Widget 选择要显示的事件。

请参阅完整的 主屏幕小部件指南 以获取屏幕截图。

如何添加锁屏或 StandBy 小部件？
  1. 长按锁定屏幕并点击 Customize。
  2. 点击时钟下方的小部件条，选择 Left。
  3. 点击 Done。

对于 StandBy：在 StandBy 中长按小部件堆栈，点击 +，然后添加 Left。请参阅 StandBy 指南 。

小部件中的时间是如何计算的？

Left 计算从当前时刻到您当地时区的目标日期的时间。每次小部件刷新时，倒计时都会更新（通常每 15-30 分钟一次），并在您打开应用程序时立即刷新。

我可以只显示天数而不是天+小时+分钟吗？

是的。编辑小部件时（长按 → 编辑小部件），您可以选择显示样式 - 仅天、天和小时、完整细分或百分比。可用选项取决于小部件的大小。

百分比视图显示什么？

百分比视图显示一个时间段已经过去了多少时间。例如，如果您正在跟踪年份，它会显示该年已经过去了多少百分比。对于倒计时事件，它显示创建日期和目标日期之间已经过去了多少时间。

Left 没有出现在我的小部件列表中
  1. 安装后至少打开一次 Left 应用程序。
  2. 更新到最新的iOS/iPadOS和最新版本的Left。
  3. 重新启动您的设备并尝试再次添加小部件。
为什么小部件不更频繁地刷新？

iOS 管理小部件刷新预算以保护电池。打开 Left 会立即刷新所有小部件。否则，系统会安排大约每 15-30 分钟刷新一次。这是适用于所有应用程序的 iOS 约束。

我的小部件为空或显示加载状态
  1. 打开 Left — 这会强制立即重新加载小部件。
  2. 删除该小部件并重新添加它。
  3. 检查设置 → Left → 后台应用程序刷新已启用。
  4. 如果处于低功耗模式，小部件刷新频率会降低 - 这是预期的。
小部件卡住，显示旧日期

打开 Left 应用程序一次即可强制刷新。如果小部件仍然显示过时的日期，请删除并重新添加它 - 这会将小部件的数据连接重置为 Left。

为什么小部件不显示秒？

iOS 不允许主屏幕小部件显示实时秒数 - 它们只能定期更新。锁屏小部件也遵循此限制。如需实时倒计时，请直接打开 Left 应用程序。

Left Premium 里有什么？什么是免费的？

Time Left、超过20个小部件、你、壁纸、Friends、Time Between、游戏和其他核心工具永久免费。 Left Premium 解锁了更深入的方式来跟踪习惯、连续记录、特殊日期和您的一天。

如何恢复Left Premium？

打开 Left → 设置 → 恢复购买 。确保您使用用于订阅或终身购买的同一 Apple ID 登录。

Left Premium 是否适用于我的所有设备？

是的。 Left Premium 与您的 Apple ID 绑定，而不是单个设备。在登录同一 Apple ID 的任何设备上，点击 Left 设置中的恢复购买即可解锁高级功能。

Left Premium适用于Family Sharing吗？

终身购买可能符合 Family Sharing 的资格，具体取决于 Apple 的购买设置。确保在您的 Apple ID 设置中启用 Family Sharing，并且为您的家庭群组打开“共享购买”。

我的习惯是不同步到我的 iPad/其他设备
  1. 确保两台设备都登录到同一个 iCloud 帐户。
  2. 在设置 → Apple ID → iCloud → 显示全部 → Left 中检查是否为 Left 启用了 iCloud Drive。
  3. 在丢失数据的设备上打开 Left — 同步在启动时运行。
  4. 稍等片刻，然后下拉刷新事件列表。
如何在新设备上恢复我的数据？

在新设备上登录相同的 Apple ID 和 iCloud 帐户，然后安装 Left。首次启动时，Left 将自动同步您来自 iCloud 的活动和习惯。这可能需要一些时间，具体取决于您的连接速度。

如何导出或备份我的活动？

如果启用同步，您的事件将存储在 iCloud 中，这将作为您所有设备上的自动备份。目前没有手动导出功能。如果 iCloud 同步关闭，数据仅存在于您的设备上。

我可以在没有 Apple ID 或 iCloud 的情况下使用 Left 吗？

是的。 Left 在没有 iCloud 的设备上工作。您可以使用核心应用程序，无需跨设备同步。共享功能使用您的免费 Left 帐户，Apple 设备之间的自动同步需要 iCloud。
