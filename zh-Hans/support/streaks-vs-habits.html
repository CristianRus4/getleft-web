条纹与习惯

Since 是 Left 的一部分，用于跟踪已经开始的时间。您可以在这里保存想要保护的记录、想要养成的习惯，以及提醒您有意义的事情已经成为您生活的一部分的计数器。两者都是关于随着时间的推移保持一致性，但是连续记录会自动计数，而习惯则要求您按照您选择的时间表完成它。

什么是连胜？

连续跟踪跟踪自起始点或自上次重置以来的时间。它会自动增加，直到您重置为止。

连续使用不需要您每天点击的东西。例如：

  1. 不喝酒的日子。
  2. 距离你们开始恋爱关系已经过去了几天。
  3. 距离您搬到新城市已有几天了。
  4. 距离您开始个人挑战已有几天了。

关键思想是计数器保持自身运行。如果连续结束，您可以重新启动或重置计数器。

什么是习惯？

习惯会跟踪您需要完成的重复操作。您可以选择该习惯发生的频率，然后在执行时将其标记为完成。

习惯可以是每天、每周、每月或安排在特定日期。有些习惯还可能需要在同一时期内完成多个习惯。例如：

  1. 每天喝水 4 次。
  2. 每周去健身房 3 天。
  3. 每个工作日都阅读。
  4. 每月审查一次财务状况。

如果你没有在规定的时间完成这个习惯，那么这个习惯就会被打破。

他们如何在Since一起生活

打开 Since 并点击 + 按钮。您可以选择 添加条纹 或 添加习惯 。

连胜和习惯都出现在同一个 Since 区域，因为两者都与时间和一致性有关。您还可以按 All 计数器、Streaks、Habits、Today 或 Friends 过滤视图，具体取决于您想要关注的内容。

模板适用于这两种类型，因此您并不总是需要从空白项目开始。条纹模板对于有意义的生命计数器很有用。习惯模板对于具有时间表、提醒和完成目标的例程非常有用。

何时使用每一项

选择一个连续时间，除非您重置它，否则事情应该自动继续。连续记录最适合“自从……以来多久”的跟踪。

当您需要采取行动时选择一个习惯并将其标记为完成。习惯对于日常工作来说是最好的，Left 应该知道你是否完成了今天、本周或本月的工作。

例如，“不喝酒的天数”就可以很好地作为连续记录，因为它会一直计数，直到您重新启动为止。 “去跑步”作为一种习惯效果更好，因为你需要在计划的日子里完成它。

仅限习惯的功能

有些功能是特定于习惯的，因为习惯有完成数据：

  1. 习惯强度洞察显示了习惯的一致性。
  2. 习惯时间表控制何时会出现该习惯。
  3. 当一个习惯需要多次完成时，可以跟踪多次完成情况。
  4. 获取最后一次提醒如果习惯仍未完成，可以在一天结束时提醒您。
  5. 以今天为中心的视图可以显示待处理、部分、已完成或错过的习惯进度。

条纹有其自身的优点：它们简单、自动，非常适合有意义的计数器，无需每日记录即可继续移动。
