如何用iPhone Action Button打开Left

iPhone 15 Pro、iPhone 16 及更高版本上的 Action Button 可以指定运行快捷方式 - 包括直接打开 Left 的快捷方式。设置方法如下。

你需要什么

  • iPhone 15 Pro / Pro Max 或 iPhone 16 系列或更高版本 — Action Button 适用于这些型号
  • Left 安装在您的 iPhone 上
  • 快捷方式应用程序 — 内置于iOS中，无需下载

步骤 1 — 创建一个打开 Left 的快捷方式

  1. 打开 Shortcuts 应用程序。
  2. 点击 + 按钮创建新快捷方式。
  3. 点击添加操作，然后搜索“打开应用程序”。
  4. 点击操作中的 App 字段，然后选择 Left。
  5. 点击顶部的快捷方式名称，并将其重命名为 "Open Left"。
  6. 点击 Done。

第 2 步 — 将快捷方式分配给 Action Button

  1. 打开设置→操作按钮。
  2. 滑动选项，直至到达 Shortcut。
  3. 点击 选择快捷方式 并选择您刚刚创建的 “打开 Left” 快捷方式。
  4. 退出设置 — Action Button 现已配置完毕。

第 3 步 — 测试

按住 A 操作按钮 （iPhone 左上角的按钮）。 Left 应该立即打开，即使是从锁定屏幕也是如此。

高级：打开特定的 Left 事件

如果Left支持URL方案深度链接，则可以直接打开特定事件。检查 Left 快捷方式指南 了解可用的 URL 操作以及如何构建打开命名事件而不是应用程序主屏幕的快捷方式。

其他有用的 Action Button 作业

Action Button 支持一次一项分配，但您可以使用 菜单快捷方式 来呈现多个选项。使用“从菜单中选择”操作创建一个快捷方式，列出多个选项（打开 Left、启动计时器、静音）——然后，每次按下 Action Button 时都会显示一个选择器。
