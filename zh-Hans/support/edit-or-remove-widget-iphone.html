How to edit, resize, or remove a widget on your iPhone

Whether you want to change which Left event a widget shows, move it to a new spot, resize it, or remove it entirely — here's everything you need to know about managing widgets on iPhone.

Edit a widget (change what it shows)

  1. Go to your iPhone Home Screen.
  2. Long-press the widget you want to edit until a menu appears.
  3. Tap Edit Widget.
  4. Change the event, display style, or any other settings available for that widget.
  5. Tap anywhere outside the widget to save.

Move a widget to a different position

  1. Long-press any app icon or widget until icons start to jiggle (jiggly mode).
  2. Drag the widget to its new position — you can move it within the same Home Screen page or drag it to the edge to move to another page.
  3. Tap Done when finished.

Remove a widget from the Home Screen

  1. Long-press the widget until a menu appears.
  2. Tap Remove Widget.
  3. Confirm removal in the dialog that appears.

Removing a widget does not delete your Left events — it only removes the widget from the Home Screen. You can re-add it at any time.

Resize a widget

iOS does not support resizing existing widgets in place. To change the size of a Left widget:

  1. Remove the current widget (long-press → Remove Widget).
  2. Long-press an empty area → tap +.
  3. Find Left in the widget gallery.
  4. Swipe to the size you want, then tap Add Widget.

Edit a Lock Screen widget

  1. Long-press your Lock Screen and tap Customise.
  2. Tap a widget to replace it, or tap the – button on an existing widget to remove it.
  3. Tap Done when finished.

Widget not updating?

If a Left widget seems stuck or showing an old value:

  • Open the Left app once — this forces a widget refresh.
  • Remove and re-add the widget to reset it.
  • Check that Background App Refresh is enabled for Left in Settings → Left → Background App Refresh.
