如何在Left上添加好友

Friends 是 Left 中的社交层。它不是一个公开的个人资料网络，也不会让您的所有数据可见。它的存在是为了让您可以有意识地与您信任的人分享 Left 的选定部分。添加朋友只是第一步 - 朋友不会自动看到您所有的 Ahead 日期、习惯或连胜。个别项目稍后会一一分享。

第 1 步 - 登录

Friends 需要 Left 帐户。

如果您尚未登录，请打开 Friends 并点击 使用 Apple 登录。您也可以前往设置→账户，点击登录。

登录后将为您提供个人资料和唯一的用户名，以便其他 Left 用户可以找到您。

第 2 步 - 打开 Friends

打开Left中的Friends部分。如果您已登录，您将看到您的好友列表和 + 按钮。

点击+按钮，打开添加好友。

第 3 步 - 分享您的邀请链接

在添加好友、Left中显示您的邀请链接。

你可以：

  1. 复制邀请链接。
  2. 使用分享按钮分享。
  3. 通过“消息”、“邮件”或您使用的任何应用程序将其发送给某人。

当有人打开您的邀请链接时，他们可以发送或接受来自 Left 的好友邀请。

第 4 步 - 按用户名搜索

您还可以通过用户名直接添加某人。

  1. 在 Add a Friend 中，点击 Search by @username。
  2. 输入他们的确切用户名。
  3. 如果 Left 找到该配置文件，请点击 Invite。

如果他们已经向您发送了请求，您可能会看到 Accept。如果您已发送请求，该行将显示 Pending。

第 5 步 - 接受请求

传入好友请求显示在 好友请求 中。

  1. 打开Friends。
  2. 如果有待处理的好友请求，请点击顶部的人员徽章按钮。
  3. 在 Friend Requests 中，使用 Requests 选项卡接受或拒绝传入请求。
  4. 使用 Pending 选项卡查看您已发送的请求。

共享邀请是单独的。如果有人邀请您观看连胜或习惯，或者加入 Joint Ahead 约会，Friends 的顶部会出现一个铃铛徽章。点击它可打开 Requests，其中共享项目分组在 共享条纹和习惯 和 联合 Ahead 日期 下。

朋友让你做什么

当有人接受您的好友请求后，您可以：

  1. 邀请他们参加 Joint Ahead 约会。
  2. 让他们观察个人习惯或连续记录。
  3. 让他们看到选定的进展并给予鼓励。
  4. 当该朋友选择与您分享时，查看他们的共享日期、习惯和记录。

仅凭友谊并不能将所有事情公开。 Ahead 日期、习惯和连胜仅在您选择该项目并邀请该朋友时才会共享。
