How to add a Left widget on your iPad Home Screen

The iPad's large screen makes it perfect for glanceable widgets. Here's how to add Left to your iPad Home Screen so your countdowns are always visible.

Step 1 — Set up your event in Left

  1. Open the Left app on your iPad (download it from the App Store if you haven't already — Left is a universal app, so one purchase covers both iPhone and iPad).
  2. Tap + to create a new event, or tap an existing event to edit it.
  3. Set the name, date, and display style.
  4. Tap Save.

Step 2 — Enter widget editing mode

  1. Go to your iPad Home Screen.
  2. Long-press on any empty area of the screen until the icons start to jiggle.
  3. Tap the + button in the top-left corner to open the widget gallery.

Step 3 — Add the Left widget

  1. In the widget gallery, search for "Left" or scroll to find it.
  2. Tap Left to see the available widget sizes.
  3. Swipe through the sizes — small, medium, large, and extra-large (iPad-only) — and tap Add Widget.
  4. Drag the widget to the position you want on your Home Screen.
  5. Tap Done in the top-right corner.

Step 4 — Configure the widget

  1. Long-press the Left widget you just added.
  2. Tap Edit Widget.
  3. Select the event you want to display, or use Smart mode for automatic selection based on what's coming up soonest.
  4. Tap outside the widget to save.

iPad widget sizes

On iPad, Left supports four widget sizes:

  • Small (2×2) — compact, shows event name and primary value
  • Medium (4×2) — shows event name, breakdown (days/hours), and a progress bar
  • Large (4×4) — full detail with progress ring and multiple display units
  • Extra Large (8×4, iPad only) — panoramic widget showing multiple events or rich detail

Using the Today View on iPad

You can also add Left widgets to the iPad's Today View (swipe right from the Home Screen). This keeps your countdowns in a dedicated widgets panel without taking up Home Screen space. The same steps apply — long-press the Today View and tap + to add Left.
