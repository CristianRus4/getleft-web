How to add a Left widget on your iPhone Lock Screen

Lock Screen widgets let you see your Left countdowns every time you wake your iPhone — without unlocking it. Available on iPhone running iOS 16 or later.

Step 1 — Create your event in Left

Start by setting up the event you want to track:

  1. Open the Left app on your iPhone.
  2. Tap + to create a new event, or tap an existing one to edit it.
  3. Set the name, date, and choose countdown, since, or percentage display.
  4. Tap Save.

Step 2 — Enter Lock Screen editing mode

  1. Wake your iPhone and go to the Lock Screen (don't unlock).
  2. Long-press on the Lock Screen until the Customise button appears at the bottom.
  3. Tap Customise, then tap your Lock Screen (the left option, not the Home Screen).

Step 3 — Add the Left widget

  1. Tap the widget area below the clock (the rectangular strip) to add widgets there, or tap the circular area above the clock for a circular widget.
  2. The widget picker opens. Scroll or search for "Left".
  3. Tap a Left widget to add it — small rectangular widgets fit in the strip below the clock; circular widgets go above it.
  4. If a widget slot is already filled, tap the existing widget to swap it for Left.
  5. Tap Done in the top-right, then tap Set as Wallpaper Pair if prompted.

Step 4 — Choose which event to show

  1. After adding the widget, long-press the Lock Screen again and tap Customise.
  2. Tap the Left widget on the Lock Screen.
  3. Select the specific event you want to display, or use Smart for automatic selection.
  4. Tap Done.

Lock Screen widget positions

  • Above the clock (circular) — compact, fits one number or icon. Great for a single day count.
  • Below the clock (rectangular strip) — up to two small widgets or one medium. Shows event name + number.

Requirements

Lock Screen widgets require iOS 16 or later and an iPhone model that supports iOS 16 (iPhone 8 or newer). If you don't see the widget strip, update your iPhone software in Settings → General → Software Update.
