Как отображать разные виджеты Left в каждом режиме фокусировки

iOS Режимы фокусировки позволяют автоматически переключаться между различными макетами главного экрана и экрана блокировки. Вот как показать обратный отсчет Left для конкретной работы во время Work Focus - и личный в остальное время.

Как работает режим фокусировки + виджеты

Каждый режим фокусировки в iOS («Работа», «Личный», «Сон», «Не беспокоить» и любые пользовательские, которые вы создаете) может иметь свои собственные страницы Home Screen и Блокировка экрана. Когда фокус активируется, iOS переключается на этот макет, включая любые виджеты на нем. Это означает, что виджет Left, прикрепленный к главному экрану Work Focus, будет отображаться только во время Work Focus.

Шаг 1. Создайте события Left.

  1. Откройте Left и создайте нужные события для каждого контекста - например, «Срок проекта» для работы и «Праздник» для личного.
  2. Нажмите Save на каждом.

Шаг 2 - Создайте страницы главного экрана для конкретного Focus

  1. Перейдите в Settings → Focus и коснитесь фокуса, который хотите настроить (например, «Работа»).
  2. Нажмите Настроить экраны.
  3. В разделе «Домой» нажмите Выбрать и выберите, какие страницы главного экрана будут отображаться во время этого фокуса, или создайте новую специально для него.
  4. Нажмите Done.

Шаг 3. Добавьте виджет Left на каждый главный экран Focus.

  1. Активируйте режим Фокус (Центр управления → Фокус или запланируйте его в Настройках).
  2. Перейдите на страницу главного экрана, назначенную этому фокусу.
  3. Нажмите и удерживайте пустую область → нажмите + → добавьте виджет Left.
  4. Нажмите и удерживайте виджет → Edit Widget → выберите событие, соответствующее этому фокусу (например, крайний срок работы).
  5. Нажмите Done.

Шаг 4 - Повторите для каждого фокуса.

Сделайте то же самое для своего личного фокуса (или любого другого), направив виджет Left на другое событие. Теперь, когда Work Focus активен, вы видите крайний срок работы; когда личный фокус активен, вы видите обратный отсчет до праздников.

Экраны блокировки для конкретных фокусов

Вы также можете связать определенный экран блокировки (с собственным виджетом Left) с режимом фокусировки:

  1. Нажмите и удерживайте экран блокировки → Customise → добавьте Left на полосу виджетов.
  2. Коснитесь Done, затем коснитесь Focus в нижней части галереи экрана блокировки, чтобы связать ее с конкретным фокусом.

Автоматическое переключение

Установите режимы фокусировки для автоматической активации по времени, местоположению или приложению - чтобы ваши виджеты Left переключали контекст без каких-либо ручных действий. Откройте «Настройки» → «Фокус» → [Имя фокуса] → «Добавить расписание».
