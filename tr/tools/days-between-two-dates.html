Days between two dates

Select a start date and an end date to find the exact number of days between them. Results update instantly.

Select both dates above.

How the calculation works

The calculator subtracts the start date from the end date and returns the absolute number of calendar days between them. It doesn't matter which date is earlier — you can enter them in either order and the result is always positive.

The count is inclusive of neither endpoint by default: if you enter January 1 and January 3, the result is 2 days (the gap between them). This is the most common convention for duration calculations.

Common uses

  • How many days until a visa expires
  • The number of days between two medical appointments
  • Days between a contract start and end date
  • How long you were away on a trip
  • Days between two anniversaries
  • Calculating project lead times
