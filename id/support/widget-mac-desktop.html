Bagaimana cara menambahkan widget Left di desktop Mac Anda

macOS Sonoma memperkenalkan widget interaktif yang langsung ada di desktop Anda — terlihat setiap saat di belakang jendela aplikasi Anda. Berikut cara memasang Left di desktop Mac Anda.

Persyaratan

  • macOS Sonoma (14) atau lebih baru — widget desktop adalah fitur Sonoma
  • Left terinstal di Mac — cari "Left" di Mac App Store

Langkah 1 — Instal Left di Mac

Left adalah pembelian universal — jika Anda memilikinya di iPhone atau iPad dengan Apple ID yang sama, unduh di Mac dari Mac App Store tanpa biaya tambahan. Buka Mac App Store dan cari "Left".

Langkah 2 — Klik kanan desktop untuk menambahkan widget

  1. Klik area kosong di desktop Mac Anda untuk memastikan tidak ada aplikasi yang fokus.
  2. Klik kanan (atau Control-klik) pada desktop.
  3. Pilih Edit Widget… dari menu konteks.

Langkah 3 — Temukan dan tambahkan Left

  1. Di editor widget yang meluncur ke atas, cari "Left" atau gulir ke sana.
  2. Klik tombol + pada widget Left untuk menambahkannya ke desktop, atau seret ke posisi tertentu.
  3. Klik Selesai.

Langkah 4 — Konfigurasikan widget

  1. Klik kanan widget Left di desktop Anda.
  2. Pilih Edit Widget.
  3. Pilih acara yang akan ditampilkan, atau gunakan Smart untuk pemilihan otomatis.
  4. Tekan Escape atau klik di tempat lain untuk menyimpan.

Memindahkan dan mengubah ukuran widget desktop

  • Klik dan seret widget desktop untuk mengubah posisinya di mana saja di desktop.
  • Widget desktop di macOS Sonoma tersedia dalam ukuran kecil dan sedang — hapus dan tambahkan kembali untuk mengubah ukuran.
  • Widget ditempatkan di belakang jendela aplikasi dan terlihat saat Anda menampilkan desktop (usap dengan empat jari ke atas dan ke luar pada trackpad, atau tekan Mission Control).

Interaktivitas widget

Di macOS Sonoma dan versi lebih baru, widget desktop bersifat interaktif — Anda dapat mengklik widget Left untuk membuka aplikasi Left secara langsung tanpa perlu menemukannya di folder Dock atau Aplikasi.
